# ## hoisted-import (F1.133, origin D1.442-A, 2026-09-23)
#
# A static VALUE import written below a top-level `mock.module`. ESM hoists every
# static import above the module body, so the imported graph links and evaluates
# BEFORE the stub, whatever line the import sits on. `MarketplaceComponents.test.tsx`
# was red alone for its whole life on exactly this (nine such imports at
# `47c70c7ee`, all converted to `await import(...)` in `2cbd7105a`).
#
# The three files listed here on 2026-09-23 (F1.462 converted two of them on
# 2026-09-24, F1.552 the third the same day once its nine stubs were spread from
# snapshots; the kind's list is EMPTY, so it is now a zero-tolerance pin) were GREEN, and not because the stub came first: each
# mocked module links fine unmocked, and `mock.module` mutates its namespace in
# place, so the modules imported below reach the stub through their live bindings
# at CALL time. A value those modules captured at their own evaluation would keep
# the real one. The fix is the same one `2cbd7105a` made: load the modules under
# test with `await import(...)` after the stubs, then drop the line here.
#
# ## narrow-first-party (F1.134, origin D1.442-B, 2026-09-23)

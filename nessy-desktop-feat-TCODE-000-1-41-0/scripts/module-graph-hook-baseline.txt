# check-module-graph-hooks baseline — the module-graph hook family as it stood
# when the guard landed (P6.862, 2026-09-08). One FILE per line, `#` starts a
# comment. The gate is red only on a NEW file.
#
# ## What this file is, and what it is NOT
#
# It is the first ENUMERATION of the family. Until now every member was found by
# a lane meeting a red: `capability-detail-registry.test.ts` carried a
# hand-written 60_000 below its own measured floor for as long as the file
# existed, and nothing could have said who else was in the same shape.
#
# It is NOT a list of 42 broken tests. The guard matches a SHAPE — a
# `beforeAll`/`beforeEach` that pays a dynamic `import(` — and a shape is not a
# cost: a hook importing one small module is in the shape and will never time
# out. The register's own rule applies to every line below and to the sweep:
# size against a ZERO-CASE CONTROL (`bun test <file> -t '<matches nothing>'`) on
# a cold tree, never against a warm reading and never by copying a neighbour's
# number. Some of these will measure well inside the 5 s default and need no
# budget at all; recording that measurement is the fix for those.
#
# ## The population as measured, 2026-09-08
#
# 50 hooks in 173 of 1 958 test files: 7 on a shared budget, 1 on a named
# constant of its own (`PAGE_IMPORT_BUDGET_MS`, the escape hatch the budgets
# module documents), 4 on a bare number, 38 with no budget argument at all.
#
# ## The four bare numbers — read these first; a written number looks decided
#
# This is the class that cost the measurement the guard was born from, because a
# hand-written budget reads as a considered one:
#
#   slash-command-help-table.test.ts:55   120_000
#   capability-info-pages.test.tsx:68      60_000   <- the same number and the same
#   loop-skill-runtime.test.ts:19          60_000      shape as capability-detail-registry
#   runtime-switch-session.test.ts:226    240_000      carried before P6.859 raised it
#
# ## The 38 with no budget cluster in three places, and the clusters matter
#
#   11  packages/server-core/src/sessions/__tests__  + 5 beside them  — the
#       `SessionManager.ts`-rooted graph, which is the family's original subject
#       and the most expensive one in the repo.
#   10  packages/shared/src/__tests__/unified-network-interceptor.*  — ten files
#       importing one interceptor graph; whatever the right answer is, it is the
#       SAME answer ten times, so measure once.
#    6  apps/electron/src/renderer/playground/__tests__  — the registry suites,
#       the same shape as capability-detail-registry, which DID need 600 000 ms.
#
# Sweeping them is a plan row, not this guard's job — a sweep folded into the
# guard that catches sweeps is how a baseline becomes a backlog nobody reads.
#
# ## THE SWEEP — P6.870, 2026-09-10 (W9-ce)
#
# The 40 findings are converted CLUSTER BY CLUSTER, one zero-case control per
# cluster rather than 40 hand-written numbers, and each converted member's line
# leaves this file in the same commit that converts it. Every member goes onto
# `MODULE_GRAPH_HOOK_BUDGET_MS` — the family's shared export — because a bare
# number is the thing this guard was born to find.
#
# Read the controls the way the budgets module says to: a zero-case control
# prices the FILE's whole module graph with the tests subtracted, so it is an
# UPPER bound on the hook's own dynamic import and a LOWER bound on what the
# file costs. Either way it settles the only question the conversion asks —
# whether 5 000 ms is enough — and in all three clusters it is not.
#
# ### Cluster 1 — the interceptor (10 files), converted 2026-09-10
#
# `packages/shared/src/__tests__/unified-network-interceptor*` import ONE graph
# rooted at `unified-network-interceptor.ts`: whatever the right answer is, it
# is the same answer ten times, so it was measured once.
# Control (W9-bq, quiet tree, 2026-09-10): `unified-network-interceptor.sse.test.ts`
# **15.16 s with 0 cases executed**, u0.70 s0.39 — about 4 % cpu, which is I/O
# and not contention. That is **3.0x bun's 5 000 ms default before a single case
# runs**, so none of the ten can be left on the default. 600 000 ms is 40x that
# reading, and the margin is the family's rather than one invented here: the
# same family measured 2.19 s warm and 354.41 s cold on identical bytes (162x,
# W7-ag), so one control is one reading of a spread that wide.
#
# ### Cluster 2 — the `SessionManager.ts` graph (15 files), converted 2026-09-10
#
# `packages/server-core/src/sessions/**` plus one `handlers/rpc` suite beside
# them: the family's original subject and the most expensive graph in the repo.
# Control (W9-bq, quiet tree, 2026-09-10): `create-session-managed-mode.test.ts`
# **58.71 s with 0 cases executed**, u1.89 s1.13 — again about 4 % cpu, and
# **11.7x the 5 000 ms default** before a case runs.
#
# TWO of the four bare numbers were here, and the pair is the argument for the
# shared site rather than for tidier literals. `runtime-switch-session.test.ts`
# carried 240_000 with its own measurement written beside it — **161.9 s at load
# 7.78 on a cold transpile cache** for the `SessionManager.ts` import alone.
# `loop-skill-runtime.test.ts` imports THE SAME module in the same directory and
# carried **60_000**, i.e. a budget nearly three times BELOW its neighbour's
# measured cold floor. That is `capability-detail-registry`'s defect exactly —
# a written number reading as a considered one — and neither file could see the
# other. Both now take `MODULE_GRAPH_HOOK_BUDGET_MS`; the 240_000 comment's
# readings are kept, since they are the reason the hook is budgeted at all.
#
# Two lines left this file WITHOUT being converted here: they were already on
# the shared budget and stale in the baseline —
# `codex-callback-bridge-host.test.ts` (converted by W9-bq) and
# `worktree-floor-approval.test.ts`. A stale entry is a silenced future finding,
# which is the one way a file-keyed baseline can go quiet on real drift.
#
# ### Cluster 3 — the electron suites (14 files), converted 2026-09-10
#
# Six playground `registry/*` suites, two `apps/electron/src/main` suites and
# six renderer component/page suites. Control (W9-bq, quiet tree, 2026-09-10):
# `marketplace-registry.test.ts` **15.47 s with 0 cases executed**, u0.68 s0.38
# — **3.1x the 5 000 ms default**. That control is the cluster's NARROWEST
# member on purpose: its hook imports ONE registry module (`../registry/
# marketplace`) and nothing else, deliberately, so every wider member of the
# cluster costs at least what it costs.
#
# The cluster also contains a MEASURED default failure rather than an inferred
# one: `slash-command-help-table.test.ts`'s own hook comment records a **15.8 s
# hook timeout against the 5 s default** before it grew its 120_000, and
# `capability-info-pages.test.tsx` carried 60_000. Both are now on the shared
# budget.
#
# One stale CROSS-FILE claim went with them, and it is the P6.551 shape:
# `slash-command-help-table.test.ts` said its hook "carries the same explicit
# 120 s budget its sibling does" while `slash-command-menu.test.tsx` had already
# moved to `MODULE_GRAPH_HOOK_BUDGET_MS`. A sentence asserting what a DIFFERENT
# file does cannot be tested from where it lives; naming the constant is what
# makes "the same as its sibling" checkable instead of a claim.
#
# ### The 41st file — MEASURED AND DELIBERATELY LEFT, 2026-09-10
#
# `claude-transcript-resume-e2e.test.ts` is in no cluster and gets no budget,
# because the baseline's own rule above is that a member measuring inside the
# 5 s default needs none and RECORDING THE MEASUREMENT is the fix for it.
#
# Its hook pays `import('@anthropic-ai/claude-agent-sdk')`. Measured directly
# rather than through a zero-case control, because the file sits under
# `describe.if(ENABLED)` with `ENABLED = process.env.NESSY_CLAUDE_SDK_E2E ===
# '1'` — skipped by default, so a zero-case run never executes the hook at all
# and would have priced the wrong thing. Two adjacent runs at load 10.45:
# **0.43 s** and **0.52 s** (u0.09/u0.10), against the vendored SDK 0.3.233 with
# provenance asserted from the repo root. That is a tenth of the default.
#
# And the budget would not merely be unnecessary — it would be WRONG in the one
# direction that matters here. This hook also calls `startAnthropicStub()` and
# talks to it; a 600 000 ms ceiling would let a hung handshake sit for ten
# minutes in the only run that ever executes this file (a human passing
# `NESSY_CLAUDE_SDK_E2E=1`), where 5 000 ms fails it honestly. Sizing UP is a
# cost, not a free margin.
#
# ## THREE MEMBERS SEEN ONLY ONCE THE SCANNER LEARNED THE CHILD-BUN SHAPE — UB12.26, 2026-10-16
#
# The guard now also matches a hook that pays its module graph in a CHILD bun
# (`Bun.spawn([process.execPath, <module>])`), the shape `registry-render.test.ts`
# brought. The three files below were in that shape long before the guard could
# see it (F1.309, F1.311, F1.312 — 2026-09-23 and earlier): each `beforeAll`
# writes a child script importing `sources/api-tools.ts` or
# `sources/credential-manager.ts` and waits on it under a hand-written 120_000.
# They are recorded here, NOT converted: nobody has taken a zero-case control or
# a cold total for them, and moving a hook with no kill timer from 120 000 to
# 600 000 ms is a cost (a hung child sits five times longer), which is the
# sizing rule's own objection to rounding up without a reading. Measuring and
# converting them is a deferred plan row (UB12.26's born row), not this guard's
# job.
#
# ### The three, measured and converted — UB12.31, 2026-10-16/17
#
# Their lines left this file in the commit that converted them, so "the three
# files below" above now names files no longer listed. A zero-case control
# skips a `beforeAll`, so each was priced by whole-file totals instead (fresh
# bun transpiler cache, inherited by the child; the OS page cache cannot be
# dropped here): **16.96 s, 19.02 s and 30.87 s** at loads 7.95-8.39 on
# 2026-10-16, **66.11 s, 51.47 s and 45.96 s** at loads 10.02-14.20 on
# 2026-10-17, and **88.41 s** for the first file on bun's default cache at cpu
# 0.02 — every one under 0.11 cpu, the family's I/O signature rather than a
# warm run's. That largest total is 0.74 of the old 120 000, a number nobody
# had read, and past the cost ledger's 0.5 warning; on the shared budget it is
# 0.15. So each took `MODULE_GRAPH_HOOK_BUDGET_MS`, which gives the cost ledger
# a ratio to print, and the kill timer `registry-render.test.ts` carries, which
# answers the objection above: the child is killed 30 s inside the budget and

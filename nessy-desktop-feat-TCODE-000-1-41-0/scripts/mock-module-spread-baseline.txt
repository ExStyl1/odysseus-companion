# check-mock-module-spread baseline — the restore-from-a-LIVE-namespace sites as
# they stood when the guard landed (P6.979, 2026-09-10). One FILE per line, `#`
# starts a comment. The gate is red only on a NEW file.
#
# ## What each line below actually is
#
# `mock.module` MUTATES the imported namespace object in place, so an identifier
# holding that object holds the MOCK a moment later. Each of these three files
# captures the real module as a live namespace (`const real = await import(…)`),
# spreads it into the replacement — which is fine, a spread copies the values as
# they are at that moment — and then restores with `() => real`, which hands the
# mock straight back. The restore runs, reports nothing, and leaves the mock
# installed for every later file in the process. Measured cost when it was first
# met: six manufactured failures in a suite the lane had not touched
# (`docs/superpowers/specs/2026-08-21-measured-traps.md`, §"Spread AND restore"
# is NOT enough).
#
# The fix is one line per file and does not change what any test asserts:
# snapshot before the first mock (`const real = { ...ns }`, from an
# `import * as ns`) and restore from the snapshot. It is deliberately NOT done
# here: all three files belong to other lanes' zones, and a guard that arrives
# with its own subject already edited cannot be reviewed as a guard.
#
# ## Not a list of three broken tests
#
# None of the three fails today. The damage a live restore does lands in a
# DIFFERENT file, later in the same process, and `bun test` ignores the order of
# the paths it is given — so which file pays is not a property of these three.
# That is exactly why the shape is worth a gate and a red is not.
#
# ## Removing a line
#
# Convert the file, then drop its line — or run `--update-baseline`, which
# rewrites the entry list from the live findings and keeps this preamble. A
# baselined file that is no longer a finding is named as a WARNING on the
# summary; it is not a failure.
#
# ## The list is EMPTY, and that is the end state (P6.982, 2026-09-10)
#
# All three original entries were converted the day after they were recorded:
# each captures `{ ...ns }` from an `import * as ns` before the first mock and
# restores from that snapshot. So the gate is now a ZERO-TOLERANCE pin — any new
# restore-from-a-live-namespace is red on the commit that writes it, with no
# line here to hide behind. Do not re-populate this list to make a red go away:
# the fix is one line in the offending file, and the preamble above says which.

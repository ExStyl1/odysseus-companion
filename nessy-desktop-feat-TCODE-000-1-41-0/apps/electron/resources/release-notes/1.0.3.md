# Nessy Desktop 1.0.3

July 7, 2026

## NEW

- Added the **Nestor Cloud Agent** provider — a native cloud code-agent that runs on the Nestor A2A protocol and connects with one-click Nessy Gateway sign-in. The agent runs its reasoning and tool loop in the cloud while file, shell, and MCP tools still execute locally through Nessy's permission boundary, with the conversation transcript kept on your machine. The provider card is available by default; a build can opt out with `NESSY_FEATURE_PROVIDER_NESTOR_CLOUD=0`.

# Nessy Desktop 1.14.0

July 23, 2026

## NEW

- Pi sessions now have a Claude-class runtime harness: deferred capability search, persistent goals, a cross-session Agent View, readable permission rules, lifecycle hooks, and redacted execution receipts share one server-owned authority.
- Claude Desktop `.mcpb`/`.dxt` extensions can be installed directly. Node, Python, and native servers are normalized into the same plugin runtime, while sensitive configuration stays in the encrypted credential store.

## IMPROVED

- Background shells, subagents, and workflows are tracked as one cancellation tree with truthful settlement, bounded continuation state, cold/lost recovery visibility, and owner-checked controls.
- File-changing tools create conflict-safe checkpoints, and command hooks use the normal permission, isolation, supervision, and receipt pipeline.

## FIXED

- Plugin-provided MCP servers no longer masquerade as editable Sources or ask to create a source that already ships inside the plugin.
- Plugin compatibility now reports plugin-declared LSP, generic settings, and effectful agent/MCP/HTTP hooks as normalized but inactive instead of claiming runtime support that is not wired.
- Session capability, agent, skill, MCP, permission, and hook decisions stay pinned to the same generation across compaction and resume instead of being rediscovered mid-turn.

# Nessy Desktop 1.0.2

July 6, 2026

## NEW

- Added two new permission modes, **Plan** and **Accept Edits**, so teams can choose between review-first planning, edit-only automation, and the existing Auto/Bypass controls without changing workspace policy by hand.
- Added persistent agent memory support with a `/memory` slash command, a local MEMORY.md store, a read path for agent context, and a `remember` session tool for capturing durable project notes.
- Added task list support for Pi sessions, including a persisted todo state, a `todo_write` session tool, and activity cards that show live task progress in the conversation.
- Added file checkpoints for agent writes, with a session-menu revert action so edited files can be rolled back from the app after a run.
- Added background shell tracking for long-running commands, including BashOutput and KillShell support so sessions can inspect or stop registered shell work.
- Added Pi backend lifecycle hook events for session start, session completion, and task completion, making automations and UI progress updates more consistent with agent activity.
- Added per-agent elapsed-time display for subagent and workflow cards, including stable completion timing once an agent has finished.
- Added playground coverage for the new parity UI states, including todo cards, orchestration progress, and session-menu actions.

## IMPROVED

- Improved Pi orchestration parity by sharing the same safety and engineering prompt guidance with orchestrator subagents.
- Improved permission safety with a sensitive-path deny list that protects credentials, SSH keys, certificates, and other high-risk local files from accidental automated access.
- Improved shell execution safety with an opt-in macOS seatbelt sandbox for approved bash commands.
- Improved prompt context by loading a personal `CLAUDE.local.md` tier alongside project instructions when present.
- Improved session hygiene by wiring retention cleanup to the `retentionDays` preference.
- Improved Pi event handling so binary and media tool output is guarded before it can flood the transcript.
- Improved release packaging by staging helper servers during Electron builds and by failing loudly when required Pi/session server resources are missing.
- Improved macOS release CI by keeping the active signed release path focused on macOS while Windows and Linux release jobs remain parked until matching runners are ready.
- Improved dev docs and update-feed publishing paths so install links, language navigation, and publish artifacts resolve consistently.

## FIXED

- Fixed Nessy Gateway auth checks on app startup so the app silently refreshes or probes DP auth before showing a login-required prompt.
- Fixed Pi/Nestor sessions to use the live shared DP JWT for the built-in Nessy Gateway connection instead of a stale per-connection token copy.
- Fixed packaged DMG installs missing `pi-agent-server`, which caused `piServerPath not configured. Cannot spawn Pi subprocess` when starting a Pi session.
- Fixed packaged helper resources by bundling the Pi server, session MCP server, and the required `koffi` native module into Electron release builds.
- Fixed Pi lifecycle events being emitted per turn instead of per session.
- Fixed elapsed timers in agent cards continuing to tick after completion.
- Fixed Claude native binary verification in macOS release packaging so the release check matches the feature flag that controls whether the binary is bundled.

# Nessy Desktop 1.0.7

July 8, 2026

## NEW

- Added a shared local tool runtime for Nestor Cloud and Pi-backed local file, shell, search, and notebook tools.

## IMPROVED

- Improved Nestor Cloud A2A sessions so remote agent tool calls execute through the same local permission, path-scope, and checkpoint boundary as local Pi sessions.
- Improved Pi built-in tool execution to use the shared runtime while preserving the existing Pi approval wrapper, tool names, schemas, and workflow/subagent behavior.

## FIXED

- Fixed approval-modified Pi `write` and `edit` calls so `file_path` updates from the approval layer are accepted without adding `file_path` to the model-facing schema.

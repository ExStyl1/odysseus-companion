# Nessy Desktop 1.0.11

2026-07-09

## NEW

- Added type-aware Add Automation prompts for Scheduled, Event, and Agentic automations.
- Added first-class automation tools for agents: `automation_list`, `automation_create`, `automation_update`, and `automation_validate`.

## IMPROVED

- Improved automation create and update flows so the UI and agents share one validated service with full-config validation before writes, atomic writes, and stable ID-based addressing.

## FIXED

- Removed the dead CLI redirect that pointed agents at the non-existent `nessy-general-agent automation` command.
- Changed direct `automations.json` edits to be blocked with guidance to use the automation tools instead.

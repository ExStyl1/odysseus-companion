# Nessy Desktop 1.35.0

September 10, 2026

The largest release of the runtime-parity work so far. Most of it is one idea: a
thing the app could do on one runtime it can now do on all three, and where a
runtime genuinely cannot, it says so instead of going quiet.

## NEW

- **A chat can run AS an agent.** Pin one of your agents to the whole conversation and its system prompt and tool restrictions apply to every turn, not just to a spawned child. The composer shows `@name` beside the mode so you can see which agent is answering, and a runtime switch tells you when the pin cannot survive it.
- **Headless runs can supply agents without writing files.** `nessy-general-agent --agents '<json>'` registers subagents for one run, and a broken agent file is now reported when it is read rather than staying invisible until a session starts.
- **Send one message the other way — Alt/Option+Enter.** Steering and queueing were a per-connection setting; now a single message can override the connection's default without changing it, and the shortcut is rebindable from the Shortcuts page like any other.
- **Reopening a long, idle conversation asks first.** Instead of silently re-sending the whole history on every later request, a card offers "Resume from summary" or "Resume full session as-is" and says what each costs. It asks once.
- **A permission answer can carry a note.** Yes or No, you can type a sentence and the model gets it — as the reason if you deny, after the result if you allow. It works on Pi, Claude Code and Codex. "Always allow" deliberately does not take one: a note explains one answer, a rule outlives it.
- **`/branch` — branch a conversation in place.** The turn button already forked and switched you in; now there is a spelling you can type, so branching exists even where there is no transcript to click. Branching from a cold Codex session was built and switched off by a flag whose reason had already been refuted; it is on.
- **Web search works on Claude Code and Codex again.** A key-free engine that had shipped in the app for one runtime now serves all three, filling the hole the vendor's own withholding leaves. A session on a native wire keeps the runtime's own search instead of being shown two.
- **`/diff`, and diffs you can annotate.** A working-tree patch opens in the viewer on every runtime, and a line-anchored comment on a diff reaches the next turn as one batch — identically on all three.
- **`/hooks` lists what will actually run.** One place showing every hook this session will run, grouped by event, with each hook's matcher, handler type and source file.
- **`/config` changes a setting from the prompt**, over a stated allowlist. It was offered by the menu on every runtime and dispatched by none — a typed `/config` used to reach the model as prose.
- **`/status` says what this session is really connected to** — base URL, credential source, provider and proxy — and the menu finally offers it.
- **A project's own commands can be saved as named actions** — dev server, tests, build — and launched from the app, per platform, behind an operator kill switch that says when it is off.
- **The session list says which chats are waiting for you and what they are waiting on**, carries a one-line summary of what each is doing, and lets you answer a blocked session from the list itself — once.
- **A read outside the working directories now asks.** In auto mode the first such read raises a card with three answers — Allow once, Keep allowing, Block from now on — and the last one really persists, in every later session. An operator can set the fence directly, and it binds in every mode including Bypass.
- **Restrict a session to a set of built-in tools.** `sessionAllowedTools` and `sessionDisallowedTools` are real settings now, in a file the app does not overwrite on every launch — the previous home was rewritten from the bundled copy at each start, so the feature had never had an input.
- **A transcript verbosity switch** — Normal, Verbose or Summary — on one key, on every runtime.
- **Safe mode can be entered and left from inside the app**, so a broken configuration no longer sends you to a terminal. A broken `config.json` is offered two ways out, and neither erases anything.
- **A settings-diagnosis page inside the app**, plus a provenance checkup that finally names *which file* supplied an effective setting — including the second settings stack a Claude Code session loads on its own.
- **Each session gets its own scratch directory.** Temp files no longer cost an approval card, and parallel sessions stop colliding on the same paths.
- **Worktrees grew a policy and a fan-out.** A root, a retention count, an off switch and a permanent kind the sweep leaves alone; a worktree can be branched from a merge request and the session wears its number; and one request can fan out into N worktree-isolated agents on N branches.
- **A blocked Codex turn can ask you a clarifying question**, on the card the host already owns.
- **Out-of-scope work the agent notices becomes a chip you click** — it proposes a session instead of starting one, and the click is isolated.
- **The built-in browser asks before it goes somewhere new.** Navigation and DevTools attach are two gates with a per-origin card, the trust list is revocable from Settings and says where the session has been, and an operator has a lock for the debugger separate from the pane.
- **A stored credential says it is about to expire, a week ahead, on all three runtimes.**
- **Scheduled tasks can be paused, resumed, run now and marked read**, and they carry the model and effort their runs dispatch on.
- **A chat can be kept out of memory, and stays kept out.** The per-chat memory scope reaches Codex's own `[memories]` table and the Claude child's environment, and the app remembers the choice.
- **Never-persist is a first-class setting with a badge** that stays visible for the life of the session and says what it costs.

## IMPROVED

- **A retry finally looks like a retry.** One chip on all three runtimes with the attempt, the runtime's own reason and a countdown that moves — and it clears when the retry succeeds on Claude Code and Codex too, not only on Pi. A retrying Codex turn used to be pushed onto the transcript as a failure.
- **`/code-review` can hand the composer back on Pi**, a chord (`mod+shift+b`) moves the tool call a turn is blocked on into the background on Claude Code, and Codex says by name that it cannot. `/simplify` and `/security-review` ship beside `/code-review`, and the review effort level is remembered across sessions instead of being forgotten every time.
- **The MCP panel says which servers are actually broken** — live pool status, not just stored config — and a single server can be reconnected without restarting everything.
- **`/context` works on Claude Code and Codex.** A session can say which `CLAUDE.md`, `CLAUDE.local.md` and rules files actually loaded, Claude's own structured context report is kept rather than fetched and thrown away, and where a runtime has no category breakdown the overlay says why instead of showing an empty box.
- **A running subagent says what it is doing**, and one that cannot report a token split says that rather than showing a blank.
- **Plugins reload in place.** A plugin change asks the Claude runtime to reload its own plugins before the session is thrown away, and the notice names what the reload cost. The Plugins page's Refresh action reaches a real server call and its toast reports what actually happened. The install scope is offered rather than guessed, and `plugin enable` exists beside `plugin disable`.
- **Importing a Claude Code setup carries subagents and slash commands**, where a switching user's customisation actually lives; a second scan says which side drifted since the import and whose copy wins; and a Codex setup is read by the same scan, so the other runtime this product ships is no longer a dead end.
- **The official vendor marketplace and skill catalog are delivered**, so following the vendor's own documentation finds something instead of nothing.
- **Rewind explains itself.** The rewound prompt goes back into the composer without destroying the draft it opens over, the menu offers Summarize with your own instructions, and a rewind now names the bash-made and background-subagent edits it could not have restored.
- **Cost and usage read honestly.** The readout names the model, where the price came from and that it is an estimate; both of Codex's cache counters are read at last, in Codex's own convention; and `/heapdump` answers whether memory is growing rather than printing six numbers.
- **Secrets are scanned on every runtime.** Tool results on Claude Code and Codex are scanned the way Pi's already were, and the scan reaches the machine-readable payload, not only the text.
- **Operators got the controls they were missing** — turn the background-agent surface off on all three runtimes, forbid personal-key and BYO authentication so a gateway-only policy actually holds, ship a subagent or an output style that outranks the same-named project one, and hear about a managed policy that failed to load or failed to arrive instead of it failing in silence.
- **The permissions page is readable.** It says how its two scopes compose, marks a workspace rule the defaults already grant as inert, shows what the auto-mode judge refused, and makes the judge's own rules readable so a deployment stops instructing a second model in secret.
- **Traced runs are one trace.** The host's turn span reaches Codex's per-request trace field and Codex's own spans reach the operator's collector, instead of a run arriving as two unconnected traces.
- **A cross-session message has a setting.** Accept, hold for approval, refuse — or leave it unset, with the selector hidden when an operator's environment already decides it.
- **Settings that had a reader and no way to set them now have one.** The Claude explore/plan agents toggle, a system-prompt append, the model-switch consent flag, the file-checkpointing switch and the two session tool lists are operator-shaped, so they surface in the configuration checkup and the settings reference rather than beside the model picker — with each row saying which file supplied the value in force.
- **Notifications have categories and a channel selector**, and a Codex session can raise a desktop notification at all.
- **An unrecognised model id is named once**, with the catalogue it was checked against, and an operator can alias it onto a served model or declare that it reasons.
- **Sessions on a page the model fetched can tell it is a stranger's text.** A fetched page is bounded and visibly fenced instead of arriving as bare prose, and web fetch can ask a model to read the page for it behind the opt-in the tool already had.
- **The app speaks Russian in two more places** — the browser toolbar window and its trust card, and the server page's TLS rows.

## FIXED

- **`/help`, `/config`, `/mcp` and `/diff` no longer collapse into one paragraph.** A multi-line answer renders its lines, and the row it renders in can be selected and copied.
- **A Codex session continues where it left off after a restart.** It used to open a fresh thread while the app showed you the full transcript, so the model had not seen the conversation you were looking at.
- **A Codex process that dies before answering now ends the turn with a named error**, instead of a session that waits forever. The callback bridge's port bind is retried too — a failed bind silently cost half the tool surface.
- **A `$HOME` in a Bash command no longer defeats the denied-path floor**, and an allow rule whose `*` sits before the deciding word no longer approves options inserted after it.
- **A `pkill` whose pattern matches the agent's own process is refused** before it ends your session mid-turn.
- **`.codex` is a protected directory** on both lists, and GitLab tokens are redacted — both of GitLab's token prefixes, not only GitHub's.
- **A sandbox denial says what it refused.** It used to arrive at the model as a bare `Operation not permitted` naming neither the path nor the host.
- **macOS stops asking for Desktop, Documents, Downloads and Music with a blank prompt.**
- **A reattached skill is no longer truncated in silence** — a body that was cut says so.
- **A switch onto Codex says what it drops.** Codex cannot read subdirectory `CLAUDE.md` or path-scoped rules, and it used to lose them with nothing said; the switch now names the loss before you commit to it. A cold managed Codex home no longer comes back holding 87 re-extracted bundled skills the off switch could not reach.
- **The `@` file picker returns files on every runtime.** Only Codex implemented it, so a Pi or Claude Code session's `@` menu was MCP resources alone and switching runtimes lost file mentions with nothing said.
- **A plugin subagent in a subfolder is scoped by its subfolder** — it was not merely mis-named before, it was absent.
- **Installing a plugin by name refreshes the marketplace first**, so one published since your last refresh is found; a marketplace's own credential now reaches an entry's archive download on the same origin instead of 401ing; and a renamed marketplace is announced.
- **Removing a worktree takes its branch with it** — narrowly, only one the host made and only when git agrees — instead of leaving one behind per worktree ever created.
- **An empty file and a read past the last line get the notice they are owed**, and only one of them arms the write gate: a past-the-end read used to grant a later write that the read-before-write rule exists to require.
- **The Claude attribution block stops reaching the gateway's model**, through the runtime's own opt-out.
- **`DO_NOT_TRACK` and `DISABLE_TELEMETRY` silence the Claude child too**, and an ambient `OTEL_LOG_RAW_API_BODIES=1` no longer exports the whole conversation from it.
- **Switching to Codex no longer re-enables memory you turned off** — the host's auto-memory switch reaches Codex's own `[memories]` table.
- **The browser download folder has a Browse button** instead of a text field that told you the path was wrong only after you typed it.
- **A rejected keyboard shortcut says it was rejected**, and a hand-edit to `preferences.json` no longer does nothing until you relaunch. The reduced-motion setting is honoured as a setting, not only as an OS media query.
- **An archived chat that is still waiting for an answer says so**, where you actually are, and the close-time keep-or-remove offer for a worktree comes back when the chat does instead of vanishing on navigation.
- **A learned image refusal is written down once and quoted back to you**, on every runtime — the endpoint's own sentence, instead of the refusal being relearned every turn on one runtime and never on the other two.

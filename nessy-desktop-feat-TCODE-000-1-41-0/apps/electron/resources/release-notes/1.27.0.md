# Nessy Desktop 1.27.0

August 15, 2026

## NEW

- **You can change a chat's integration after it has started.** Until now the choice was locked the moment you sent the first message: picking a different integration meant opening a new chat and re-explaining everything. The picker now offers every integration on a conversation that is already under way, and the switch happens in place. The chat keeps its name, its project, its files and its history.

- **The conversation goes with you.** Moving between integrations that run on different agents means handing the conversation from one to the other, and Nessy now does that hand-off for you: the new agent is given what was said before and carries on from it. Moving back to an agent you were on earlier is different again — that agent still has its own memory of the conversation, so it picks up where it left off and is told only what it missed while you were away, rather than being read the whole thing a second time.

- **You are told what the move costs before you make it.** Changing the integration on a started chat asks first, and the question names the specific things that will not survive: background agents that will be stopped, a plugin's monitor that will stop running, images already in the conversation that the new agent cannot see. Choosing a different model within the same integration is free and asks nothing — it is only a change of agent that needs the warning.

- **Switching integrations from your phone.** The iOS app can move a session to a different integration too, with the same confirmation and the same summary of what stops.

## IMPROVED

- **The context meter belongs to the agent you are on now.** Every agent measures its context differently, and after a switch the meter used to be able to show one agent's usage against another's capacity — a number that looked reasonable and was not. The meter now resets with the switch and refills from the agent actually running.

- **What was running on the old agent is stopped, not orphaned.** A repeating prompt scheduled with `/loop`, a background agent, a plugin's always-on monitor: all of these belong to the agent that started them. They are now shut down as part of the move instead of continuing to run against a chat that has gone elsewhere, and the ones that can start again do when you come back.

- **A permission you granted is not carried somewhere you did not grant it.** An "always allow" is an answer about one agent. It no longer follows the conversation onto a different one, which will ask you again.

## FIXED

- **A chat can no longer be moved out from under a running reply.** Asking to switch while the agent is mid-answer is refused until the turn finishes, instead of tearing down an agent that is still writing.

- **Quitting during a switch lets the app close.** A switch in progress no longer holds up shutdown.

- **Deleting an integration cannot silently move a live chat onto another one.** The chat now says its integration is gone rather than quietly continuing somewhere else.

- **Leaving a worktree happens before the agent changes**, so a session cannot come out of a switch pointing at a directory that no longer exists. If there is uncommitted work that would be stranded, the switch stops and says so.

# Nessy Desktop 1.0.5

July 7, 2026

## NEW

- Added `/context`, `/export`, and `/init` composer commands for inspecting token context, exporting a transcript, and generating starter project memory from the chat input.
- Added custom workspace slash commands from `.nessy/commands/*.md` and `.agents/commands/*.md`; each command appears in the slash menu and runs its markdown body as the prompt.
- Added selectable output styles, including workspace-defined `.nessy/output-styles/*.md` personas that shape the system prompt on new turns.
- Added **Auto** permission mode, which lets low-risk work proceed while keeping risky actions behind the safety classifier and approval prompts.
- Added path-scoped memory rules from `.agents/rules/*.md` and `@import` / `@path.md` expansion inside memory files.
- Added user-configurable lifecycle hooks so workspace automation can react to agent session, task, and tool events.

## IMPROVED

- Improved Claude Code parity across the composer by rounding out non-blocking slash commands, custom commands, output style control, and memory rule loading.
- Improved docs for working-directory memory, permission modes, and CLI mode values.

## FIXED

- No dedicated bug fixes in this release; this update focuses on parity features and documentation.

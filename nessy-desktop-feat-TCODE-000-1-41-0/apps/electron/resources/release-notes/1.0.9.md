# Nessy Desktop 1.0.9

July 8, 2026

## NEW

- Added built-in trust for the T-Bank corporate CA on Node-based API, OAuth, and model requests.
- Added Network settings for using the bundled CA, disabling it, or selecting a custom PEM certificate path.

## IMPROVED

- Improved custom API endpoint setup so TLS-intercepted corporate endpoints can be validated without disabling TLS verification.
- Improved proxy documentation with bundled CA behavior, custom CA configuration, and process-start `NODE_EXTRA_CA_CERTS` fallback guidance.

## FIXED

- Fixed OpenAI-compatible custom endpoint checks failing with `UNABLE_TO_GET_ISSUER_CERT_LOCALLY` when the server certificate chains to the T-Bank corporate CA.

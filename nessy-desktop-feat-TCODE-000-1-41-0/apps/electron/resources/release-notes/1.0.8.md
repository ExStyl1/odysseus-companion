# Nessy Desktop 1.0.8

July 8, 2026

## NEW

- Added a production-ready plugin runtime foundation with safe install planning, Nessy-owned cache storage, trusted capability enablement, and user/workspace/project visibility.
- Added support for native Nessy plugin bundles, compatible Codex-style local plugin bundles, marketplace metadata inspection, plugin-provided skills, MCP descriptors, and trusted command hook registration.

## IMPROVED

- Improved runtime refresh so plugin and hook configuration changes are picked up by active sessions before the next queued turn observes stale capabilities.
- Improved docs for plugin marketplace behavior, plugin skills, plugin MCP projection, and hook trust boundaries.

## FIXED

- Fixed plugin status and reload paths to use the same projection resolver as runtime sessions, including project `.nessy` overlays and capability overrides.

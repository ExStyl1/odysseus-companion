# Nessy Desktop 1.1.0

July 17, 2026

## NEW

- Added the extension-first Pi agent runtime: one shared tool executor with immutable permission receipts, a supervised process authority with per-workspace isolation profiles, and a closed curated extension host with no dynamic discovery.
- Added durable agent orchestration for Pi conversations: tasks, ask-user questions, plan approval, background subagents with steer/stop, mailboxes, and git worktree leases.
- Added the Agent Runtime panel in the right sidebar showing live tasks, subagents, processes, checkpoints, context usage, compaction state, and pending permissions.
- Added file checkpoints with one-click rewind for Pi tool edits.
- Added LSP provisioning for trusted projects and a deferred MCP tool surface with on-demand loading.

## IMPROVED

- Unified provider tool adapters so the Nessy Gateway Qwen dialect and the Nestor A2A boundary route through the same executor, permission, and receipt path.
- Improved Desktop/server projection with bounded, validated runtime snapshots that omit prompts, file paths, message bodies, and secrets.
- Improved reconnect recovery with epoch-guarded invalidations so stale connections can no longer install outdated runtime state.

## FIXED

- Fixed legacy working-directory updates to canonicalize the path before it reaches runtime and persisted state.
- Fixed stale test contracts and the isolated test sweep so the full offline gate runs green end to end.
- Fixed the bundled Pi runtime losing its package identity, which blocked sessions with a version mismatch in built and packaged apps.
- Fixed session tool resolution for host-registered tools whose canonical model name differs from their registration name.
- Fixed permission receipts for background, subagent, and workflow tool calls by binding them to the requesting session-build epoch.

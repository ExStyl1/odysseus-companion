# Nessy Desktop 1.21.1

August 8, 2026

## NEW

- A subagent can carry its own hooks in its markdown file. They run only while that subagent is working and stop when it finishes — and a hook belonging to one subagent no longer fires when a different one completes.
- The agent panel now shows what each subagent actually ran on: its reasoning effort and its model, beside the status it already showed.

## FIXED

- Asking the agent to update a plugin now installs the newer version. Like the Update button before it, the agent's own plugin tool used to reinstall the version you already had and report success; it now fetches the newer one, or says plainly that it cannot find one instead of claiming an update that did nothing.
- The headless server resolves plugin updates the same way the desktop app does. Its two surfaces disagreed: an update asked for by the agent worked while the same update over the API refused, even with the catalog already loaded.

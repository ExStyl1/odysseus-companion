# Nessy Desktop 1.21.0

August 8, 2026

## NEW

- A skill can now run in a forked subagent. Add `context: fork` to its frontmatter and the skill runs in isolation, driven by its own content, without your conversation history — and its result comes back to you when it finishes. Set `background: false` if you want to wait for it in the same turn.
- A skill's frontmatter can define hooks that run only while that skill is active — the documented example being a security check before every shell command — and stop the moment the skill finishes.
- When you send work to the background, you are told when it is done. A background subagent's result now returns to the conversation on a later turn instead of quietly finishing where only the side panel could see it.

## IMPROVED

- Updating a plugin actually fetches the new version. Clicking Update used to reinstall the version you already had and report success; it now installs the newer one, and refuses honestly when it cannot find a newer version in the catalog instead of claiming an update that did nothing.

## FIXED

- A skill argument can no longer smuggle a shell command into the skill's instructions by replacing one of the skill author's own placeholders. The guard against this now compares which commands are present, not merely how many, so a one-for-one swap is caught — while a skill that deliberately runs your input still works.

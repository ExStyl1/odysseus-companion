# Nessy Desktop 1.38.0

September 13, 2026

The tail of the coverage-95 parity plan, and the three runtimes lifted to the newest
versions the corporate mirror carries. Most of this release is the kind of change you
only notice when it stops happening: a sign-in prompt that no longer interrupts a chat
that was working, a proxy that now reaches the shell your agent runs commands in, an
Escape key that closes the dialog you opened. The plan closes with the honest figure it
measured rather than the one it was named for.

## NEW

- **All three runtimes lifted to the newest versions the corporate mirror carries.** The
  Claude Agent SDK moves 0.3.247 → 0.3.251 (the bundled `claude` reports 2.1.251; it now
  performs the denied-path exclusion on search results itself, and gains `PreModelSwitch`
  and `PostModelSwitch` hook events and a per-server MCP tool timeout), Codex moves
  rust-v0.150.1 → rust-v0.154.0 (four new app-server methods including `thread/revert`,
  two provider auth-recovery notices, fifteen more feature flags), and Pi moves 0.84.3 →
  0.84.4. Every constant this app derives from a bundle was re-read against the new one;
  two designed tripwires fired and were re-taken rather than silenced, and a parser that
  would have invented a Codex feature name at its first dot was fixed on the way.

- **The Developer Platform sign-in stops interrupting your work.** A turn never waits on
  the `dp` command-line session on any runtime. If that session has ended, the chat keeps
  answering and the session shows one notice naming `dp auth login`; only the Developer
  Platform tools themselves refuse, by name, with what to do. The notice distinguishes
  the two states it used to confuse: your session has ended, or Nessy could not reach the
  `dp` command line at all and cannot tell.
- **`WorktreeBatch` works on all three runtimes.** The host's own fan-out over an isolated
  worktree per unit was Pi-only for a reason that stopped being true; it now reaches
  Claude and Codex sessions as well, with the no-pull-request boundary unchanged.
- **Reasoning streams on the Claude runtime.** Thinking arrives as it is written instead
  of appearing as one finished block at the end, the way it already did on Pi.
- **The model picker says where its list came from.** The catalogue's origin is named
  under the list, so a gateway catalogue and a BYO endpoint's models are no longer
  indistinguishable.
- **A subagent's permission card says who is asking.** A card raised by a background agent
  names the agent instead of appearing anonymous.

## IMPROVED

- **A shell write into a protected file now asks first.** `>> ~/.zshrc` through the shell
  raises the same permission card the file tool would; `.git` is deliberately left off that
  floor so `git commit` keeps working without a prompt.
- **A shell approval on the Claude runtime can be remembered for the session**, the way the
  card already offered for other tools — for this session only, never written to a
  settings file.
- **`/code-review` on the Codex runtime runs in the background by default**, as it already
  did on Pi and Claude; the foreground escape stays available.
- **A background hook has a documented budget.** A hook marked `async` runs under the same
  command budget as its siblings instead of an implicit thirty seconds, and the place the
  app differs from Claude Code's documentation says so.

- **The app's proxy now reaches the shell commands your agent runs.** When Nessy is
  pointed at a proxy, the shell children of a Pi or Codex session inherit it, as the
  Claude child already did. A network your administrator routes through a proxy is no
  longer bypassed by a `curl` inside a turn.
- **Escape closes every chat dialog**, not only the rewind menu — agents, context and
  usage panes included, through the dismissible-layer registry the app already had.
- **Codex titles run on the cheap model.** Naming a chat no longer spends a main-model
  turn on the Codex runtime, which is what the Claude runtime already did.
- **A hook that times out tells you whose budget ran out** and the two ways past it,
  instead of a sentence that offered nothing.
- **Codex hook messages reach you.** A hook's own message and its reason for stopping a
  turn are surfaced on Codex the way they already were on Claude.
- **The Codex change card names the files it is about.** A patch card that could not name
  what it was about now can, the protected-path floor sees those paths, and a card that
  still cannot name its act refuses to offer a durable grant.
- **Plugin installs stop calling a broken bundle complete.** A component directory holding
  the wrong file extension says so, and the install reports the bundle as partial.
- **The composer stops capitalising the first word** when it is a keyword a runtime reads
  as a token, so `ultrathink` reaches the model as written.
- **Session names survive.** A chat named at creation keeps its name, and a name is no
  longer lost when you switch the runtime.
- **The connection you cannot delete tells you who holds it** — the chats and background
  tasks using it, by name.
- **A silent model substitution is named.** When something other than the card's model
  answers, the session line says so.

## FIXED

- **An inline API key no longer lands in `config.json` in plain text.** Creating a
  connection with the key typed inline wrote it verbatim into the config file, and
  updating one dropped it entirely; both paths now go through the credential store.
- **A zero-byte transcript no longer survives deleting a Claude session**, and a session
  that re-minted its anchor no longer leaves an unreachable transcript behind.
- **The rewind menu's actions reach the rewind the app performs** — they addressed an id
  the server did not know.
- **The compaction that hung a background Pi agent is gone.** The step that timed out
  after fifteen seconds was building the whole session, not compacting it.
- **A worktree batch unit whose prompt never arrived** is no longer reported as a branch
  to submit.
- **The permission gate's additional-folders list leads with the folder you chose** as
  primary.
- **A Codex session no longer projects a subagent model its own catalogue refuses.**
- **The Developer Platform probes stop racing their own binary.** Both `dp` calls were
  budgeted at five seconds, which is exactly how long the binary's own startup step takes
  when its host is unreachable; they now run concurrently with a budget sized against it.

## KNOWN

- On a headless run, stopping the process can leave shell children behind on Pi, and
  killing the spawned server reports success; the Claude and Codex arms differ from each
  other too. Measured this release, fixed in the next one.
- A hook file's `SessionStart` and `SessionEnd` do not fire on the Claude runtime, where
  Pi and Codex both run them.

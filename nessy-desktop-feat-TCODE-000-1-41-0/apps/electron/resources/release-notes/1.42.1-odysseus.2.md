# Nessy Desktop — быстрые переключения и системный терминал

2026-10-21

## NEW

- Запуск CLI явно открывает системный «Терминал» macOS и подтверждает запуск процесса CLI.

## IMPROVED

- Сканирование навыков, MCP и истории вынесено в отдельный фоновый процесс.
- Периодический статус синхронизации не перерисовывает всю оболочку, если видимые данные не изменились.

## FIXED

- Фоновый цикл больше не вызывает дорогой метод подготовки списка сессий для интерфейса.
- Запуск CLI использует свежие общие ключи без повторного сканирования профиля, пока работает синхронизатор Desktop.
- При ошибке системного запуска кнопка возвращается в обычное состояние и показывает ошибку.

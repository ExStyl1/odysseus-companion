# Odysseus: общие чаты и запуск CLI

2026-10-21

## NEW

- В Desktop, запущенном через Odysseus, доступны «Открыть в CLI» и ручная синхронизация.
- Совместимые чаты, каталоги моделей, выбранная модель, язык и светлая/тёмная тема синхронизируются локально каждые пять секунд.

## IMPROVED

- Секреты передаются через штатный менеджер учётных данных Desktop и приватный зашифрованный мост; API-ключи для CLI передаются только дочернему процессу.
- Общие данные и резервные копии хранятся вне исходников приложений. Установщик интеграции проверяет совместимость после раздельного обновления исходников.

## FIXED

- Конфликтующие истории и незавершённые записи не перезаписываются. Сессии с агентом защищены от входящих изменений.
- Перенос истории сохраняет оригиналы и вложения в приватном архиве. Действия инструментов переносятся как текст, без исполнения и без переноса разрешений.

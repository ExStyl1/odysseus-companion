# Nessy Desktop 1.36.0

September 11, 2026

The runtime-parity plan's finish line: all three runtimes lifted to the newest versions
Artifactory carries, the last product postures decided by one rule (closest to the runtime's
own documentation, least code, simplest host coverage), and a day of small holes closed where
one runtime quietly did less than the other two.

## NEW

- **The Nessy Gateway retired its coder model, and the app now follows the gateway's own alias instead of a pinned id.** A one-click gateway card is seeded from the catalogue's `coder` alias (and its default flag when present), a stored default the gateway no longer serves is replaced at start with one line in the session log naming both ids and the tier, the fast tier resolves to the `fast` alias before any keyword guess, and the model that is the default today has a fallback context window for the start where the refresh fails. Before this release a fresh card's first turn could answer 404.
- **Claude Agent SDK 0.3.247 (Claude Code 2.1.247).** Fourteen versions of the vendored runtime, reconciled native-first: the runtime's own `autoContinueAtUsageLimit` decides resume-vs-stop at a usage limit, prompt-cache TTL and model pricing are read from the SDK instead of re-implemented, the auto-mode classifier receives the host's `classifierContext` note framed, and the per-task stop affordance is declared so an interrupt keeps background tasks alive exactly as before.
- **Codex rust-v0.150.1.** The app-server, the Windows sandbox trio and the protocol bindings move together; twelve hook events, five new managed requirements with verdicts read from the source, stdin approvals told apart from command approvals, and the runtime's own strict-review demand surfaced when it ships.
- **Pi 0.84.3**, with the dev bundle's identity pinned by a test that runs the shipped resolver over both layouts.
- **`/rewind` restores files on Claude Code.** File checkpointing follows the same host setting Pi and Codex already read; the runtime takes the checkpoints, the app only asks.
- **Claude Code's native `EnterWorktree` passes the host floor.** The tool now receives the repository facts it needs and nothing it enforces itself.
- **`/code-review` runs in the background by default** on every runtime, with the foreground fallback kept as the documented escape; `/simplify` and `/security-review` say the same direction in their own words.
- **Workspace Settings shows both budget ceilings** — the token and the USD limit — as read-only, operator-owned values, and the two notices that used to tell you to raise a limit you could not raise now say whose limit it is.
- **The reopen dialog has its third answer**: silence it from the dialog itself, as the page describes.
- **A managed `sandbox.filesystem.disabled` reaches the approval dialog** — the one delivered sandbox key the app carries no longer bypasses it.
- **A documented `file` marketplace delivery source works** beside `directory`.
- **The settings flag `--settings` is honoured as a contributor**, and both silences it used to produce — a dropped path, a key a floor kept — are said to the operator instead of only to the debug log; narrowing `settingSources` names what it dropped, and `--bare` is answered rather than aliased.
- **`NESSY_CROSS_SESSION_INBOUND` is read as a managed value**: an unreadable setting refuses and the settings card says so instead of offering a selector that cannot change the outcome.
- **The switch-cost dialog gains the read fence** (host policy on Pi and Claude Code, absent by design on Codex) and the corrected `sessionAgent` row for Pi.
- **`$CLAUDE_JOB_DIR/tmp/f` no longer prompts** — the one variable the page spells resolves in the scratch exemption, nothing else expands.
- **`init.skills` and `init.agents` are carried** from Claude Code's session start where `slash_commands` already landed.
- **A switched-off local server wears a hollow ring** so two greys stop being the same dot; settings rows whose description is a value wrap instead of ellipsising it.
- **Twenty-nine live cases for the release sitting** ship in `scripts/cdp/cases/rs-*.ts` — nineteen drive by name (`bun run scripts/cdp/run.ts RS-15`), the rest are recipes with a named detector and a positive control.

## IMPROVED

- The SDK's withhold set grew 93 → 123 names at 0.3.247; all thirty new ones (AWS, GCP and CloudSDK credentials among them) are classified and applied on the confirmed path.
- The `claudeMd` managed-approval class stays until the vendored runtime reaches 2.1.260, with the date and the flip point written beside it.
- 309 line-numbered `settings.md` citations in source comments became section anchors with the sentence quoted from the page; the guard that ratchets them reads zero.
- The three build scripts refuse an unset update feed before packaging; the renderer build refuses on any externalization warning.
- The CDP harness enumerates sitting cases by directory, a recipe can never be scored as a wave case, and a module-graph budget can be seen to be outgrown before it is a red.

## FIXED

- **A fresh gateway card's first turn could answer 404** — the card seeded a model id the gateway had retired, and offline nothing could repair it before the turn. Seeded from the catalogue alias now (above).
- **Session titles, mini completions and summarization ran on the flagship on all three gateway cards** — the new coder id contains the word the small-model keyword guess looks for. The `fast` alias is asked first.
- **`⌥ENTER` in the shortcuts page** — the shipped send-alternate default rendered as the word; it is `⌥↩` on macOS and `Alt+Enter` elsewhere.
- **The mode description promised "approval granted in advance" on a runtime that refuses unattended calls** — the codex clause of the bypass-permissions note now says what happens without a person attending, and which setting opens the fallback.
- **Two session RPC verbs were registered and declared nowhere; the iOS wire-error mirror lacked `CONNECTION_GATEWAY_ONLY`; the hotkey grammar refused the app's own `alt+enter`; a usage metric already on the wire was not in the record** — all four caught by the release wave gate and fixed.
- **Codex: `approval_policy = "untrusted"` is fatal at rust-v0.150.1** — the release schema dropped it and the app-server exits before `initialize`. Every mode with the sandbox off wrote it; all seven now degrade to `on-request` with an operator notice.
- **Pi: every session carrying `review` died on its first turn** for a day — a model-visible description changed and only half of its contract hash was re-pinned. Re-pinned, both bundles rebuilt, and the sitting drives a `/code-review` first turn.
- **A workspace lift can leave stale nested copies of the lifted packages** shadowing the root install; the Pi bundle briefly built against 0.84.2 while the lock said 0.84.3. Provenance is now asserted from each workspace.
- `fetch-codex.mjs --all` refetched nothing after a tag bump; the idempotent skip now sees the tag.
- `sessionAgent`'s Pi cell said `false` after Pi gained the capability, and a drift test had been red on its first pair since 2026-09-09.
- The `ask_user` card on Pi answered nothing for either reopen answer; it now matches the pending id.
- Seven Codex tests pinned a denied-path floor of 19 that had grown to 24; a notification family union of 72 that had grown to 79.
- Three config-suite tests whose premises moved under landed commits, a hook-cost guard's own control, and the `runtime-info` tag literal.

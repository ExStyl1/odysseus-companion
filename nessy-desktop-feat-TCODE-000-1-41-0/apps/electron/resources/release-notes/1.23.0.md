# Nessy Desktop 1.23.0

August 10, 2026

## NEW

- Nessy can now serve your phone over an encrypted connection. When the server listens on a network address, it creates its own certificate and prints a fingerprint; the phone shows the fingerprint it actually received and asks you to confirm the two match before pairing. If a paired server's certificate ever changes, the connection is refused rather than quietly accepted — on a shared network that change is what an impostor looks like.
- Pairing by QR code. The Server settings page now shows a code that carries the address, the token and the certificate fingerprint together, so pairing is one scan instead of typing a URL and a 32-character secret by hand. The same code works as a link if you would rather send it to yourself.
- A remote device can no longer switch a session into "bypass permissions". Modes up to and including auto stay available from a phone, but the one that stops asking altogether is refused by the server — not merely hidden in the app, so it holds no matter what is connected.

## IMPROVED

- Connecting to a server that has no TLS now says so, and offers to connect without encryption in one tap while stating plainly what that costs. The previous behaviour was an opaque SSL error that sent you looking for a certificate problem you did not have.
- Serving on a network address no longer requires you to obtain a certificate first. If you deliberately want an unencrypted connection on a trusted network, `--allow-insecure-bind` still does exactly that, and now takes precedence rather than being overridden.

## Nessy for iPhone and iPad

The companion app is now part of this repository and carries the Nessy name, icon and theme, in Russian and English.

It browses your workspaces and sessions, streams replies as they are written, and — the reason it exists — lets you answer a permission request while the agent keeps working on your computer. You can stop a running turn, switch model and permission mode, send the agent a task that keeps running after you close the app, and attach a photo or file that is saved into the session on your computer rather than living inside one message. Skills and sources are listed read-only. Themes come from the same theme files the desktop uses, so a theme added on the desktop appears on the phone.

A session that has stopped and is waiting for your answer rises to the top of the list with a badge, and the number of them shows on the app icon — so a question reaches you without opening the app. The list also says which computer you are connected to, and which workspace within it.

Away from the app, the session list stays readable from a local cache behind a clear offline banner, and the connection re-establishes itself when you come back. An iPad shows the session list and the conversation side by side, and a second device does not disconnect the first.

The app reaches your computer over your local network. Access from outside that network is not part of this release.

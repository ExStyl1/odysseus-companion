# Nessy Desktop 1.0.12

July 13, 2026

## NEW

- Added storage layout v2 with immutable Workspace IDs and globally partitioned conversation storage.
- Added one scoped capability catalog for native and plugin skills, MCP servers, hooks, agents, automations, Sources, and related runtime resources.

## IMPROVED

- Separated Nessy-managed Workspaces from external Projects so one Workspace can be used across several repositories without copying project data into app storage.
- Improved plugin storage with install-once immutable bundles, content-addressed cache entries, scope-specific activation, isolated writable data, and revision-pinned runtime snapshots.
- Improved project, executable, credential, and remote Workspace boundaries with backend-owned handles and path-free renderer contracts.

## FIXED

- Replaced legacy data migration with a crash-safe clean cutover that quarantines an eligible default home without importing or deleting its contents.
- Fixed plugin capability materialization so normal and agent-driven conversations receive the same captured skills, MCP servers, hooks, and metadata.
- Fixed capability descriptions and Show in Finder actions after the storage/runtime cutover.
- Fixed development launches with an empty `NESSY_CONFIG_DIR` so they use the normal default storage root.

# Nessy Desktop 1.29.0

August 17, 2026

## NEW

- **Switching a session to another runtime now tells you what the move costs.** The confirmation you already answer lists the capabilities the runtime you are leaving has and the one you are moving to does not — ranked so anything affecting your files is read first. It is per direction, not per runtime: moving onto Pi lists nothing at all, because nothing is lost that way. What it says was checked against the code rather than written from memory, and four of the five differences the list was originally going to name had already been fixed and were dropped.

- **The permission mode you pick now says what the runtime underneath it can actually enforce.** A mode states your intent — "ask me first", "go ahead" — and that does not change with the runtime. What changes is how much of it the runtime can hold you to. On Codex the app does not inspect each action before it runs, so every mode there now carries one extra sentence saying so, and Plan adds that there is no plan to hand you. On Pi and Claude nothing extra appears. Workspace Settings deliberately keeps one description per mode: a workspace has no runtime, so intent is the only honest thing to state there.

- **The model can ask you a clarifying question on Claude.** It could already do this on Pi. The question reaches the same option cards, with the same wait timeout, and your answer goes back into the turn.

- **The model can ask for the conversation to be compacted on Claude.** The request is answered honestly — the Claude runtime cannot compact in the middle of a turn — and then carried out the moment the turn ends.

- **A subagent on Claude now carries the skills its definition declares.** The same agent was previously weaker on that runtime than on Pi. Its per-skill tool restrictions, model ceilings and budget come with it.

- **An agent that declares it must run in an isolated copy of your repository now gets one on Claude.** Before, that declaration was dropped in silence and the agent wrote straight into your working directory.

## IMPROVED

- **Permission rules you write in Claude's own settings file now take effect on the Claude runtime.** They were being read and then applied everywhere except the runtime whose format they are. A rule that says "ask me about this" now asks.

- **The strictest permission mode is no longer the most permissive one on Codex.** With the sandbox off — which is the shipped default — the mode meant to never prompt was configured in a way that also never asked the app, so nothing checked anything. It now denies whatever no rule has pre-approved, which is what that mode means everywhere else.

- **The app says when an imported agent's hooks cannot be carried.** Claude cannot run them, and the notice now names the agent instead of the agent quietly running without them.

- **Retries, rate limits, compaction and permission refusals from the Claude runtime now reach the session.** Twenty-one kinds of message that arrived and were dropped are surfaced; seven more are dropped deliberately, each for a reason written down beside it.

## FIXED

- **After compacting on Claude, the context indicator showed nothing while the banner said the conversation had been compacted.** Two numbers were involved and the app was reporting one for both: what the turn cost, and how much context is left. A compaction turn sends the entire conversation to be summarized, so those are very different figures. They are now reported separately — the indicator shows what remains, and usage still records what was actually spent.

- **A compaction the model asked for on Claude was promised and never happened.** The reply said it would run at the end of the turn; nothing ran. It runs now.

- **A message typed while a turn was still running could be destroyed.** If the model had asked to compact during that turn, the text was discarded with no error and no queue entry. It is now kept and re-sent.

- **The runtime-switch confirmation no longer clips its own content.** Longer integration names were truncated, and on a short window the buttons could be pushed off the edge — asking a question that could not be answered.

## KNOWN OPEN

- **Keeping a Claude session alive between turns is designed but not built.** The design exists and is deliberately not shipped on reading alone: the pieces it depends on were verified by documentation rather than by running them. It moves to its own plan, with the live measurements it needs named up front.

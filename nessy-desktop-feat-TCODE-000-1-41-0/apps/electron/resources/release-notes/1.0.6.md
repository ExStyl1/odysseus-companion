# Nessy Desktop 1.0.6

July 7, 2026

## NEW

- Added ephemeral in-memory sessions for automation prompt actions and spawned child sessions. Opted-in sessions run without writing session records or metadata to disk and disappear after close or restart.
- Added live Nestor Cloud composer modes from the A2A AgentCard. The mode picker, slash menu, and Shift+Tab cycle now use the cloud agent's advertised modes while keeping the static Plan/Act fallback.

## IMPROVED

- Improved context usage and compaction reporting for Pi and Nestor Cloud. Pi can refresh live context usage, `/compact` updates the meter immediately, and Nestor Cloud shows remote-reported usage only when the agent provides it.
- Improved context-window metadata for the built-in Nessy Gateway models. The internal Qwen models now use the gateway-confirmed 262,144-token window, and startup model refresh self-heals older persisted 131,072-token values.
- Improved docs for automation prompt sessions, long-running conversation context, Nestor Cloud modes, and Gateway model metadata.

## FIXED

- Fixed the context meter understating the built-in Nessy Gateway model window when the gateway models endpoint omits context-window fields.

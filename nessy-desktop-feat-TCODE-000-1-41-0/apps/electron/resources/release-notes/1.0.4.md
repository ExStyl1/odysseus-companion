# Nessy Desktop 1.0.4

July 7, 2026

## NEW

- Added the `/automations` slash command — open the automations panel straight from the chat input.
- Added the `/usage` slash command — show the current session's input, output, total, and context-window token counts, plus cost when the provider reports one.
- Added the `/agents` slash command — browse the built-in and workspace-defined agent definitions (name, description, tier, tools) discovered from your workspace.
- Surfaced all five permission modes — **Explore**, **Plan**, **Ask**, **Accept edits**, and **Execute** — in the composer mode picker, the SHIFT+TAB cycle, and Workspace Settings. Previously only Explore, Ask, and Execute were offered.

# Nessy Desktop 1.33.0

August 22, 2026

## NEW

- **`/quota` now works on the built-in Nessy Gateway (Pi) connection too.** The daily token budget it reports is the same per-user gateway limit your Pi sessions on that card already spend from — so the answer is one command away on both connections that share it: Nessy Cloud and the built-in Nessy Gateway. Bring-your-own-endpoint Pi connections are deliberately excluded — they have no Nestor budget to report, and showing someone else's numbers would be worse than saying "not available". Expired gateway credentials now surface as an actionable warning (sign in again) instead of a transient note.

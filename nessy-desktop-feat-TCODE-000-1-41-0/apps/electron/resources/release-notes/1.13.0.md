# Nessy Desktop 1.13.0

July 21, 2026

## NEW

- The project trust dialog now shows what a repository actually contributes before you decide. Opening an untrusted project lists its AGENTS.md/CLAUDE.md instructions, `.nessy-agent` config, MCP server configs, skills, and hooks — read-only, path-free, and detected without executing anything.
- Installed plugins can be inspected again after trusting: the Sources panel re-runs the same read-only contribution detection so you can review what a project brings at any time, not only at the trust prompt.
- Per-capability plugin toggles: an installed plugin's individual MCP servers, skills, hooks, and commands can now be switched on and off one by one from the plugin's detail page — disable one MCP server out of ten without losing the other nine.
- A capability you switch off leaves the running chat's tool set immediately (the shared MCP pool shuts the server down unless another chat still uses it) and comes back the moment you re-enable it.

## IMPROVED

- Disabled plugin components render dimmed with a "Turned off" note on the plugin page, and the corresponding Sources row shows why it is disabled — a per-capability switch is distinguishable from a plugin disabled as a whole.
- Disabling a whole plugin stays terminal: per-capability switches can never resurrect a capability the plugin-level toggle suppressed.

## FIXED

- Trust-dialog contribution detection is hardened against hostile repositories: non-regular files (FIFOs, sockets) and oversized configs are skipped without reading, so an untrusted project cannot stall the dialog.
- Capability toggles only accept ids the plugin's manifest actually declares, so the policy file cannot fill up with junk records.

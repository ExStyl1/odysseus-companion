# Nessy Desktop 1.20.1

August 7, 2026

## IMPROVED

- A busy Nessy Gateway no longer ends your turn in about fourteen seconds. A throttled request is now retried five times, waiting 15, 30, 60, 120 and 240 seconds — long enough to cross a full per-minute limit window instead of giving up inside one.
- You can see it happening. The status line says what went wrong and how long the wait is — "Rate limited by the provider — retry 2/5 in 30s" — instead of a bare attempt counter that looks identical to a hung session, and it clears as soon as the retry succeeds.
- Subagents back off for 5 seconds rather than 250 milliseconds when a child fails to start against the gateway, so a fan-out stops hammering an endpoint that has just asked it to slow down.

## FIXED

- Retry messages no longer claim a rate limit for every retry. The same mechanism fires for timeouts, server errors and dropped connections, and those now say so.

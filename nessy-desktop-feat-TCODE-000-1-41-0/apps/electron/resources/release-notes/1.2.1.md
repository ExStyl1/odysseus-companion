# Nessy Desktop 1.2.1

July 17, 2026

## NEW

- The Pi agent now reports a complete lifecycle hook inventory. Working-directory changes, file changes, post-compaction, and MCP tool interactions are surfaced as observational events alongside the existing session, tool, permission, subagent, task and worktree hooks, each with a frozen ordering and delivery contract.

## IMPROVED

- Workflow orchestration scripts are now bounded: a runaway synchronous loop or unbounded output is stopped instead of freezing the agent, while normal multi-step workflows are unaffected.

## FIXED

- A workflow script can no longer block the Pi agent with an infinite loop or oversized synchronous output; such scripts now fail cleanly with a clear limit error and the agent stays responsive.
- The new lifecycle hooks are strictly observational and cannot alter a tool-permission decision; only the existing pre-tool-use and permission-request hooks remain decision-bearing.

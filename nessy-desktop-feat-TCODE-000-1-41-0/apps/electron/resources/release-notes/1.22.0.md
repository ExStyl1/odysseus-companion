# Nessy Desktop 1.22.0

August 9, 2026

## IMPROVED

- The Claude Code engine moves up to the newest build available on the internal mirror, bringing its own fixes for leaked listeners on streamed replies, clearer diagnostics when the engine exits unexpectedly, correct status reporting on rate limits, and resuming sessions whose id begins with a dash.
- The limit on how deep agents may delegate to other agents now applies to both engines. Setting it applied to one of them and was quietly ignored by the other, so a session could nest deeper than you had allowed.

## FIXED

- When a tool is refused — for example a file write in Explore mode — the assistant now tells you so instead of stopping mid-turn. The refusal used to end the whole turn before the model could say anything, so you asked for something, nothing happened, and nothing explained why.
- Sending a message while a reply is still streaming no longer pushes that reply below your new message. The answer to what you asked first now stays above what you asked second.
- A message queued mid-reply no longer makes the assistant believe its own finished answer was cut off, so the next turn no longer opens by apologising for an interruption that never happened.
- Quitting can no longer be derailed by its own cleanup. If any shutdown step failed, the app used to stop half-way — and an update being installed at that moment stayed downloaded but never applied.
- If the final handoff to the updater does not complete, the app restarts itself instead of lingering with nothing running.
- The app no longer refuses to start because another program happens to be using the process number written in a leftover lock file. The lock now records which program wrote it, and a mismatch is treated as stale.

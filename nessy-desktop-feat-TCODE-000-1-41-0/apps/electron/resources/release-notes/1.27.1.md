# Nessy Desktop 1.27.1

August 16, 2026

## FIXED

- **Your saved keys open again on a machine that could not read them.** The encryption key is derived from your machine's hardware identity, and when that identity could not be read the app quietly fell back to a second one. A store written under the fallback could not be opened afterwards — every API key read as simply missing, with no explanation. Those stores now open and are re-encrypted under the current identity automatically. Nothing was ever lost; it was unreadable, not deleted.

- **A machine that genuinely cannot open your keys now says so, and says what to do.** It used to show an empty list of connections, which reads as "you have not added anything". The message now explains that the keys are still on disk, encrypted on a different machine identity, and that entering a key again continues from there and leaves the old file untouched. Worth knowing: **the credential store is the only thing in your configuration tied to a specific machine** — everything else survives a copy to a new Mac intact.

- **A read could no longer delete your credentials.** An older code path deleted the credential file when it failed to decrypt — including in exactly the case above, where the file was intact and simply keyed to another machine. That path is gone.

- **A refused integration switch now tells you why.** "A turn is still running", "there is uncommitted work in the worktree", "this session is inside a worktree it cannot leave" — three specific messages that existed, were translated, and could never appear, because the reason was lost on its way to the window. Every refusal showed the same generic failure instead. The worktree one is the one that cost something: it is the only thing telling you that your uncommitted work is why the switch did not happen.

- **`/loop` no longer appears on integrations that cannot run it.** Its scheduler exists only on one of the three agents. On the others the command was still offered, and picking it produced a confident answer about a schedule that was never created. It is now offered only where it works.

## IMPROVED

- **Less weight carried into every message.** Instructions the app repeated in every single request — preview formats, the browser command list, and each tool's description restated in prose after it was already sent — are now either referenced where they are documented or fetched when they are actually needed. About 10 000 characters left the text that accompanies every turn, which is room given back to your conversation.

- **The context breakdown stopped counting something you do not pay for.** The `/context` view listed agent definitions as one of the largest consumers of the window. Measured on the wire, that text is never sent at all on the Pi agent. The row now reports what is actually transmitted, and still lists your agents by name.

- **Tool search now activates exactly where the specification says.** At precisely 10% of the context window the threshold fires; it previously required going over.

# Nessy Desktop 1.19.0

August 6, 2026

## NEW

- **Both coding runtimes now ship in the default build.** The **Nessy · Codex agent** and **Nessy · Claude Code agent** cards no longer need a special build: a stock install offers one-click gateway sign-in for either harness, with the `codex-app-server` and Claude SDK native binaries bundled. Only the subscription cards — Claude Pro/Max and ChatGPT/Codex — stay behind build flags. A build can still opt a runtime out with `NESSY_FEATURE_CODEX_RUNTIME=0` or `NESSY_FEATURE_CLAUDE_RUNTIME=0`.
- **Bring your own endpoint to either coding harness.** A new **Custom runtime endpoint** card (onboarding and Settings → AI → **+ Add Connection**) runs Codex or Claude Code against your own OpenAI-compatible endpoint and key — an internal LLM proxy, a self-hosted vLLM, a local Ollama. The form takes the endpoint, an optional key, and the model list; the first model becomes the default. Requests to your endpoint authenticate with your key as a standard `Authorization: Bearer` header — the gateway's `Nestor-Token` never leaves for a custom endpoint.
- **Keyless local endpoints work out of the box.** A loopback endpoint may be saved without a key: the connection is stored as auth-less, its requests carry no auth header, and credential health stays green instead of demanding a re-authentication that has nothing to re-authenticate.

## IMPROVED

- **Editing a custom runtime connection is round-trip safe.** The Edit form re-opens with the stored values, the runtime choice is locked so an existing connection never silently changes harness, and leaving the key field blank keeps the stored key.
- Custom-endpoint model refresh is scoped to the gateway: a bring-your-own connection keeps exactly the model list you typed, and its catalog is never overwritten by the gateway's.

## FIXED

- Creating a keyless local runtime connection no longer leaves it looking broken — it used to persist as key-based with no key stored, which the connection test reported as "No credentials configured" and the credential-health banner nagged to re-authenticate.
- The Codex model refresh no longer treats a custom endpoint on the gateway's host as the gateway itself, which could send your own key where the gateway token belongs and overwrite your model catalog.

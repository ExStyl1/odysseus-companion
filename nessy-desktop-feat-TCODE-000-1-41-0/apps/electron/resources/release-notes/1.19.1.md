# Nessy Desktop 1.19.1

August 6, 2026

## IMPROVED

- Built-in dp MCP servers (Jira, GitLab, Sage, Wiki, and the rest of `dp ai mcp`) now run warning-free and non-interactive. Note: an already-enabled built-in server reconnects once after this update — its connection identity changed.

## FIXED

- dp commands run by the agent's shell no longer report "not authorized" while your own terminal says you're signed in — the sandbox now lets the system dp refresh its own hourly key.
- Built-in dp MCP servers no longer fail to connect silently when dp is signed out. The session-start notice now shows a one-click dp Sign in row for them, and they reconnect automatically once you sign in.

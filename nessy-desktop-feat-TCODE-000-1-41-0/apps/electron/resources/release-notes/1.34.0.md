# Nessy Desktop 1.34.0

September 4, 2026

## NEW

- **The Permissions page now says when a blocked tool is not actually blocked.** A `blockedTools` entry the runtime never consults — `Bash`, `WebFetch`, `browser_tool` and the other always-allowed read-only names — keeps its place in the table and gains a line naming the branch that decides instead, so the page stops making a safety claim the runtime does not honour.
- **Plugins can hook a model switch.** `PreModelSwitch` and `PostModelSwitch` now fire on Pi, Claude Code and Codex alike, and a `PreModelSwitch` hook that refuses really does cancel the switch — the session keeps its model and the reason reaches you.
- **Codex sessions can read MCP resources.** The connected servers' resources and resource templates are now offered to the model on Codex instead of answering empty, and a resource can be read by name.
- **Codex sessions honour the directories you added.** Folders added to a session are now writable inside Codex's own sandbox, instead of being granted by the host and never mentioned to the subprocess.
- **`/help` is answered on every runtime.** It was offered on four and implemented on none, so whichever runtime you asked replied from memory of a different product.
- **`/quota` and the model picker cost more honestly.** Switching runtimes now tells you what the new one cannot do — including that hosted web search is unavailable — before you commit to the switch.
- **`/heapdump` names the process that matters.** It used to name one process and stay silent about the one holding the conversation.
- **Nessy Gateway sessions share one MCP transport per workspace**, so several sessions in the same workspace no longer each open their own connection to the same server.

## IMPROVED

- **Attachments say when their contents did not reach the model.** A PDF, an audio file, or an Office document with no Markdown twin now carries a visible line saying the runtime is passing only the file's path — and names the runtime that does carry the bytes. Previously only the filename was sent, on both Pi and Codex, with nothing said.
- **Russian is complete on the surfaces that were half-translated.** Relative times ("5m ago" inside a translated sentence), plugin activation states, plugin install reasons, and the model-retirement warning are now translated end to end; a machine reason code is now presented as a code rather than as broken English.
- **Codex tells you when it drops something.** A model that gets rerouted, an effort level it cannot honour, an agent role it cannot declare, and a tool-output limit it applies differently are all reported once per session instead of only on the debug channel.
- **Codex classifies refusals correctly.** A policy refusal from the gateway used to arrive as a bad-API-key error, which sent the runtime off to re-authenticate instead of showing you what happened.
- **Codex teardown cannot hang the app.** Stopping a Codex session waits a bounded time for the child process and then reports a named reason, where before a child that ignored every signal could leave a runtime switch waiting forever with nothing on screen.
- **Codex subagent limits follow the host's.** The concurrent-subagent ceiling and the nesting depth you configure now reach Codex's own configuration; without them a Codex session nested one level where a Pi session nested three.
- **Permission floors report instead of failing quietly.** A PowerShell command the validator cannot parse is now refused as unparseable rather than read as "writes nothing", and a managed policy on Windows no longer trusts everything by default.
- **Claude sessions report their own context window.** The meter, the model's capabilities, and the fallback chain now come from the runtime rather than being derived by the app.
- **Subagents get an honest tool list.** A restricted subagent can no longer message a peer it is not allowed to see, and four bundled agents that answered on Pi and were "not found" on Claude Code now answer on both.

## FIXED

- **Hosted web search on the Claude runtime through the Nessy Gateway is now withheld instead of reporting success and doing nothing.** It was dispatched, marked completed, and returned zero results — with the upstream model's own attempted tool call arriving as the result text. Sessions on a model that speaks the native wire keep the tool.
- **The vision toggle no longer reports success on a write it never made.** Turning image support on for a model the connection does not list used to leave the setting unchanged and say nothing, so trying again produced the same silent nothing.
- **A slash command carrying a file no longer loses the file.** One runtime treated the attachment as prose and another dropped it silently.
- **The model-retirement notice is a real notice.** It used to be English prose inside a model description, with a hand-spelled plural.
- **Sessions marked as leaving nothing behind really do.** An ephemeral session was writing file snapshots to disk, and the setting never said so.
- **A message containing a session-path token is no longer expanded into a filesystem path when it is read back.**
- **The workspace permission-mode cycle applies everywhere.** It restricted the keyboard shortcut and nothing else.
- **Stopping a turn no longer inherits another session's shutdown**, and a Codex session that lost nine tools mid-switch is now told.
- **Spending ceilings are no longer armed on a runtime that cannot price a turn**, where they stayed silent because no turn was ever priced.
- **Plugin installs report what was deferred.** A partially-installed plugin's Confirm button now says what needs confirming, and an install the server blocks names the capability and the code rather than a bare failure.
- **131 unreachable translation keys stopped shipping**, along with seven that translated reason codes this product never emits.

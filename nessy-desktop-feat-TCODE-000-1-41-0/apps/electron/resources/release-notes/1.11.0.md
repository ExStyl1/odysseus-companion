# Nessy Desktop 1.11.0

July 20, 2026

## NEW

- Self-correcting edits. In a trusted project, when the agent edits or writes a file, Nessy runs the project's own linter or type-checker on just that file and folds the results back into the agent's context — so it fixes lint and type errors on its own before you ever see them. It only uses tools your project already has (Biome, ESLint, tsc, Ruff, mypy, …), never installs anything, and the diagnostics are advisory: they inform the agent, never block or undo an edit.
- Format on demand. A new format capability detects your project's configured formatter — Biome, Prettier, Ruff, rustfmt, or clang-format — and formats a file with it, with no language server required. Like the edit feedback, it uses only what the project already has and never installs a formatter.

## IMPROVED

- The composer's git branch switcher is far more robust. Switching with uncommitted changes no longer fails with a raw error — Nessy explains you have local changes and offers a one-click "Stash & switch" that stashes, switches, and restores your work (and never discards it, even if the restore conflicts). Outside a git repository the switcher now shows a clear disabled state instead of vanishing, and branch errors are reported specifically instead of dumping raw git output.

## FIXED

- The branch switcher no longer silently disappears when a session's folder is not a git repository, and it no longer attempts a plain checkout that would fail on a dirty working tree.

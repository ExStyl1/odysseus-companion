# Nessy Desktop 1.13.1

July 21, 2026

## NEW

- Installed plugins and marketplace items can now be uninstalled directly from **Sources** — the plugin row menu and the plugin detail page both offer Uninstall, so you no longer have to return to the Marketplace browse page to remove something.

## IMPROVED

- Multi-file marketplace skills install completely. Skills whose `SKILL.md` references sibling files (scripts, templates, evals) are fetched as a whole from the marketplace's per-file snapshot, with each file verified against its published checksum, instead of failing because a single-file download left the references missing.

## FIXED

- The agent can reach the network again. Under the opt-in macOS bash sandbox, DNS and HTTPS calls (`dig`, `nslookup`, `curl`, `git`) failed with "Operation not permitted" even when permissions were set to allow everything — the sandbox is meant to contain file writes, not block sockets. Network access now stays with the permission layer where it belongs.
- Installing a skill from the marketplace no longer fails with a GitLab "HTML page instead of a skill file" error: the install now uses the catalog's real file source instead of a repository root that required browser sign-in.

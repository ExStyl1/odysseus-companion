# Nessy Desktop 1.21.3

August 8, 2026

## IMPROVED

- The composer shows one context indicator instead of two. The ring and the warning badge beside it were both labelled "context" but divided by different things — one by the whole context window, the other by the point at which the conversation compacts — so they showed two different percentages side by side. There is now a single ring: it fills as before, turns colour as compaction approaches, and becomes a button that compacts on click. Its tooltip carries both numbers, so nothing that used to be shown has been lost.

## FIXED

- Long sessions now keep enough room to finish the turn that follows a compaction. The point at which a session compacts is checked after the model answers, so whatever it leaves unused has to cover everything the next turn adds — your message and every tool result it produces. That headroom was smaller than a single tool result is allowed to be, so one large tool call could take a session from just under the line to over the model's limit with nothing checked in between. The headroom now covers a full turn, and it grows with you if you raise the tool-output limit yourself.
- Models with small context windows are not compacted prematurely by that change. The headroom is capped at a third of the window, so a narrow-window model keeps a usable amount of history, and it can never end up smaller than it was before this release.

# Nessy Desktop 1.7.0

July 19, 2026

## NEW

- Added a `/review` command for structured code review. A read-only reviewer agent works through your change against a real rubric and returns severity-ranked findings (P0 through P3), most serious first, each with a file and line reference. You can point it at your uncommitted work, at the difference against a base branch, or at a single commit.
- Added an `/init` command that inspects the repository and writes a starter project instructions file (`AGENTS.md`) — build and test commands, structure, and conventions — so a fresh project gives the agent solid footing right away. It preserves an existing file rather than overwriting it.
- Custom agent definitions can now set `maxTurns` and `permissionMode`. Both are always clamped to the parent session's permissions, so a helper can be made stricter but never broader than the session that spawned it.
- Small-tier subagents now run on the Nessy Gateway "fast" model automatically when it is available, so read-only helpers no longer burn the flagship model. Larger tiers stay on the session model, and any explicit per-agent model still wins.

## IMPROVED

- Manual `/compact` now hands off a structured context checkpoint. Instead of a generic summary, the model that continues the session receives current progress, key decisions, constraints and preferences, remaining next steps, and critical data or references — written as a handoff, not a recap.
- The system prompt gives the agent clearer working guidance: a short heads-up before it runs a group of tool calls, a review mindset that leads with findings, and answer formatting that leads with the result and uses clickable references.
- Permission guidance now speaks to whatever mode you are in — what runs freely, what needs approval, and how to proceed when something is blocked — instead of listing every mode at once. A one-line note still reminds you the other modes exist and can be switched at any time.
- Raised the orchestration limits to match heavier automation: up to 16 concurrent subagents, nesting depth 5, and 1000 workflow agents, with the effective concurrency held to what the machine's cores can support.

## FIXED

- The renderer build no longer bundles the agent SDK, which was breaking packaged builds.
- Custom `/compact` instructions are now bounded, so a very large paste cannot crowd out the checkpoint summary.
- A child session can never exceed its parent's permission mode, including after the parent switches modes mid-session.

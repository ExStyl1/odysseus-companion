# Nessy Desktop 1.15.0

July 24, 2026

## NEW

- Administrators can enforce one host-owned Pi policy for permission modes, permission rules, plugins, MCP servers, and plugin hooks; user and project configuration cannot widen it.
- Optional OTLP/HTTP telemetry exports bounded, redacted lifecycle and terminal outcome events without exposing prompts, tool data, paths, headers, environment values, or secrets.

## IMPROVED

- MCP tool, resource, and prompt catalogs refresh atomically after server notifications, retain the last good state on failure, and withdraw removed tools before the next Pi turn.
- Portable plugin LSP, typed settings, trusted scheduled monitors, leased MCP channels, and one-line skill context commands now use the existing supervision, permission, receipt, and lifecycle owners.

## FIXED

- Trusted plugin agent, MCP, and credentialless HTTP hooks now execute through governed host runners with pinned capability checks, cancellation, timeouts, and one redacted terminal receipt.
- Disabling or uninstalling a plugin stops its LSP, skill context, monitor, and MCP work before runtime leases and immutable plugin bytes are released.

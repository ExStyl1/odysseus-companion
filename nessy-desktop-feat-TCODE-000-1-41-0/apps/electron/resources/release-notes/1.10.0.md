# Nessy Desktop 1.10.0

July 20, 2026

## NEW

- Bring your own plugin marketplace. Add a Git repository, Git URL, or local folder whose catalog lists many plugins, and its entries appear in the Marketplace grouped under their own registry section beside the built-in market. Add a registry from **Marketplace → Create → Add marketplace** (source, Git ref, and optional sparse paths); upgrade re-fetches a Git registry, and remove takes it away with a confirmation. A registry whose catalog can't be loaded is called out inline without breaking the rest of the list.
- Create your own skills and plugins with the agent. New **/create-skill** and **/create-plugin** slash commands (and **Marketplace → Create → Create plugin**) open a visible chat that interviews you and scaffolds the skill or plugin into your workspace, then validates it. Two built-in guides — **Skill Creator** and **Plugin Creator** — ship with the app and are seeded into your skills on first run.

## IMPROVED

- The "Add Skill" action now runs the same guided Skill Creator interview in a visible chat.
- Built-in skills are seeded only when missing and never overwrite a skill you have edited.

## FIXED

- Adding a marketplace registry, listing its catalog, and installing from it all run on the server through the same governed fetch path — no plugin content is fetched from the app UI, and registry file locations never reach the interface.

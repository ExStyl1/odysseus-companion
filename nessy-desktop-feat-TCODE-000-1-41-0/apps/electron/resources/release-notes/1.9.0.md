# Nessy Desktop 1.9.0

July 20, 2026

## NEW

- Redesigned the Marketplace in the Codex style. Browse plugins and skills from separate tabs with a single server-side search, cleaner flat result rows, and an "Installed" strip across the top. Each item opens a detail view with its description, information, and — once installed — the full list of what it ships (skills, commands, hooks, connectors, and MCP servers), with each component clickable through to its own page.
- Sources is now a management panel. A new **Plugins** subsection under Sources lists every installed plugin, and you can enable or disable a plugin for the whole workspace or just the active project straight from a row's menu.
- Source and skill detail pages now show their content inline: the source guide or SKILL.md instructions, the permission tables that govern them, and — for MCP sources — the list of tools the server provides.

## IMPROVED

- Installing from the Marketplace now hands you off to Sources to manage what you installed — the Marketplace stays the place to discover and add, Sources is the place to manage. Clicking an installed plugin in the Marketplace opens its management page in Sources.
- Adding a source or creating a skill through the agent now opens a visible, named chat you can watch and steer, instead of running in a hidden background session.
- MCP tools can be listed from a source's detail page even when no chat is open, using a workspace-level connection.
- While a plugin is installing, only that card shows "Installing…" — the rest of the list stays usable.

## FIXED

- Composer source selection is now consistent: local-folder and API sources are available only when selected for the session, while MCP sources stay governed by their activation state.
- Enable/disable menus for plugins now reflect the real state — an already-enabled plugin correctly offers "Disable" instead of always offering "Enable".

# Nessy Desktop 1.26.1

August 15, 2026

## IMPROVED

- **Nessy's own built-in tools now answer to ONE name, whichever agent is running.** The same tool — the one that writes your todo list, the one that validates a config file — used to introduce itself to the model under a different name on each of the three agents: `TodoWrite` on Claude Code, `todo_write` on the Pi agent, and a third spelling again on Codex, which mounted the whole set under a private server name of its own. Nothing was broken by it day to day, but three spellings of one tool is three chances for a rule, a transcript, an allow-list or a log line to disagree with itself, and it made the built-in tools impossible to describe as one set to anything outside the app. There is now exactly one spelling, the same on all three agents.

- **Codex sessions treat Nessy's built-in tools as built-in.** Because Codex mounted them under its own private name, the part of Nessy that decides "is this one of our own tools, or a tool belonging to a source you have connected?" did not recognise them, and a built-in tool call on Codex was handled as though it came from a source that had not been switched on yet. Those calls are now recognised for what they are, they carry their proper name and icon in the transcript, and they do not ask you to activate anything.

## FIXED

- **Conversations recorded before this release still read correctly.** Nothing on disk was rewritten — history is kept append-only on purpose — so older sessions still hold the older spellings. Both are now translated as they are read: an old Pi conversation shows one consistent tool name across all of its turns rather than changing spelling halfway through, and an old Codex conversation keeps the tool's own name, label and icon instead of showing a raw internal one. Resuming an older session works exactly as before.

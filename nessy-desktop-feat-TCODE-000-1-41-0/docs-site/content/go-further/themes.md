# Themes

Themes set the color palette Nessy Desktop uses. Every theme is defined against a small set of semantic colors rather than per-component overrides, so light mode, dark mode, and custom palettes all stay predictable.

## Switching Themes

Change the theme in **Settings → Appearance**. The choice applies immediately, and a workspace can override the app default with its own theme (see [workspaces](workspaces)).

## Guidelines

- Keep contrast high for session lists, code blocks, and tool output — those are read most.
- Check both light and dark appearances after a change.
- Avoid palettes that wash out status or permission colors, since those carry meaning.

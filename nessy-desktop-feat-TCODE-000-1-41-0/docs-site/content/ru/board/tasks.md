# Задачи

Задача — это работа, спланированная как спецификация, а не один разговор: `tasks/<slug>/task.yaml` в папке рабочего пространства. Карточка задачи на [доске](./overview) — это сессия-оркестратор, а каждый шаг спецификации — подзадача — выполняется отдельной дочерней сессией.

## Спецификация

- `nodes` — небольшой граф: узел запускается, когда всё из его `depends_on` завершилось, а `${nodes.<id>.output}` передаёт финальный ответ одного узла в промпт следующего. Каждая ссылка должна называть узел, объявленный в спецификации.
- `acceptance_criteria` — критерий, по которому оценивается готовая работа.
- Задача выполняется в папке своего оркестратора; папка, выбранная для задачи, должна быть доверенной.

Спецификацию обычно пишут в редакторе задачи, а не вручную.

## Редактор задачи

В редакторе задачу создают и меняют: название, цель, критерии приёмки, проект, модель и подключение оркестратора, режим прав, источники и навыки для всех подзадач, папка и сами подзадачи. «Новая задача» на доске открывает его; туда же ведут «Изменить задачу» на карточке и в заголовке чата задачи. Новая задача в проекте с папкой запускается в этой папке, если не выбрать другую; смена проекта у существующей задачи её папку не перемещает.

## Generate

Вкладка **Generate** в редакторе черновит план по цели (или названию). Generate черновит план в сессии только для чтения, которая удаляется, если её не сохранить; сгенерированный план перед первым запуском просит подтверждения запуска. Черновик ничего не пишет: он создаётся в самом строгом режиме, и действие, которое не разрешено правилом, отклоняется без вопросов. Сохранение новой задачи делает черновик её оркестратором; выход из редактора без сохранения удаляет его.

## Запуск задачи

Задачу запускаете вы: **Play** на карточке или **Create & Run** / **Save & Run** в редакторе. Оркестратор запускает подзадачи в порядке зависимостей, каждую отдельной дочерней сессией в папке задачи, и оценивает готовую работу по критериям приёмки; провал оценки отправляет названные подзадачи на доработку — до предела, заданного задаче.

Запуск задачи просит подтверждения, когда план сохранили не вы (его написал агент, черновил Generate или task.yaml изменился на диске); в подтверждении перечислены рантайм, подключение, модель и режим каждой подзадачи, источники и плагины.

**Pause** останавливает запуск новых подзадач (идущие завершаются), **Resume** продолжает, **Stop** завершает запуск. Вкладка **Results** в редакторе показывает статус запуска, оценку и её историю, состояние и финальный ответ каждой подзадачи со ссылкой на её сессию.

## Когда подзадача выполнена

Подзадача считается выполненной, когда её ход завершён и ничего из запущенного ею больше не работает: ни фоновый агент, ни воркфлоу, ни команда, ни монитор, ни запланированное пробуждение, ни активная цель. Если к концу хода фоновая работа ещё идёт, подзадача остаётся в работе и завершается через несколько секунд после окончания этой работы — с ответом, который она дала раньше (о Claude Code см. ниже). В Codex агента, запущенного через spawn_agent и оставленного работать после хода, подзадача ждёт, но его отчёт не становится её результатом: Codex оставляет его для следующего хода подзадачи. Фоновую команду, запущенную в последнем ходе подзадачи, приложение может не увидеть до того, как подзадача будет отмечена выполненной. В Claude Code после завершения фоновой задачи ассистент пишет ответ в чате подзадачи; подзадача ждёт этого ответа и берёт его своим результатом.

## Режим разрешений

Режим прав задачи — потолок для её подзадач: подзадача стартует в своём режиме, ограниченном режимом оркестратора, и каждое последующее изменение режима ограничивается заново. Если понизить режим оркестратора во время выполнения задачи, это ограничит следующее изменение режима идущей подзадачи и каждую подзадачу, которая стартует после этого; уже идущая подзадача до тех пор сохраняет свой режим. Прогон, возобновлённый после перезапуска, сохраняет режим, в котором он шёл, пока вы не измените режим оркестратора. Подзадача, которую вы сами добавили с плитки на доске, — ваша собственная сессия и не ограничивается. См. [Разрешения](../core-concepts/permissions).

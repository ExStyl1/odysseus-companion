# Доска

Доска показывает сессии рабочего пространства карточками по колонкам — канбан-вид всей идущей работы. Переключайтесь между списком сессий и доской переключателем **Список / Доска**.

## Карточки и колонки

- Карточкой становится каждая сессия верхнего уровня. Архивированные сессии, дочерние сессии и несохранённые черновики Generate карточками не становятся; дочерняя сессия показывается строкой подзадачи на карточке родителя.
- Колонки — **К выполнению**, **В работе** и **Готово**. Колонка карточки следует её статусу (`todo` → «К выполнению»; `in-progress` и `needs-review` → «В работе»; `done` и `cancelled` → «Готово»), пока карточку не перетащат в другую. Перетаскивание перемещает карточку и задаёт статус, выбранный для колонки; цвета колонок и статусы при переносе настраиваются в **Настройки → Внешний вид** и сохраняются у каждого пользователя свои.
- Закрыть работу — перенести карточку в «Готово» — может только пользователь: агент никогда не закрывает свою карточку. См. [Статусы](../statuses/overview).

## Новая задача

Кнопка «Новая задача» на доске открывает редактор задачи. Укажите название, цель и при желании критерии приёмки; выберите модель оркестратора (сгруппированы по подключениям, с рантаймом, который их обслуживает), режим прав, источники и навыки для всех подзадач и рабочую папку. Добавьте подзадачи — у каждой свой промпт, при желании своя модель и зависимости от других подзадач. Задача попадает в колонку «К выполнению». Изменить её можно позже карандашом на плитке или кнопкой «Изменить задачу» в заголовке чата задачи.

Из чего состоит задача, как работает Generate и как её запустить — см. [Задачи](./tasks).

## Проекты на доске

Выберите проекты в фильтре в заголовке доски, чтобы видеть только их карточки; «Без проекта» показывает карточки без проекта. Когда выбран ровно один проект, доска показывает его собственные колонки: нажмите на заголовок колонки, чтобы переименовать её, сменить цвет, задать статус при перемещении сюда или удалить, а кнопкой **+** добавьте новую. Первое изменение начинается с трёх колонок по умолчанию, карточки удалённой колонки переходят в первую оставшуюся, последнюю колонку удалить нельзя. Нажатие на карточку задачи открывает «Все сессии» с фильтром по этой задаче (и её проекту); фильтры снимаются как обычно. В редакторе задачи поле «Проект» относит задачу к проекту; новая задача тогда запускается в папке проекта, если вы не выбрали другую.

О самих проектах — см. [Проекты](../projects/overview).

## Задачи из разговора

Агент может добавить задачу на доску с помощью `create_board_task`. Задача попадает в колонку «К выполнению» и никогда не запускается самим агентом; она использует собственные папку, проект, подключение и включённые источники агента.

## Удаление задачи

Удаление чата задачи-оркестратора удаляет и папку задачи `tasks/<slug>/`, если ту же задачу больше не несёт ни один другой чат; при архивировании папка сохраняется.

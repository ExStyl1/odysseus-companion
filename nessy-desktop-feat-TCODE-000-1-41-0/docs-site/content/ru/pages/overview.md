# Страницы

Страница — небольшое HTML-приложение или отчёт, который живёт в рабочем пространстве и открывается в приложении, в разделе **Страницы** боковой панели. Страница подходит для того, что переживает разговор: дашборд, отчёт, к которому вы возвращаетесь, трекер, который агент пополняет данными.

## Виды

| Вид | Скрипт | Для чего |
| ---- | ------ | -------- |
| `static` | нет | готовые документы и оформленные отчёты |
| `interactive` (по умолчанию) | встроенный JS | калькуляторы, исследовательские панели, небольшие инструменты |
| `live` | встроенный JS, и получает новые данные, пока открыта | дашборды, которые вы пополняете данными |

## Библиотека

В библиотеке страниц у каждой страницы есть превью. Оно снимается в фоновом окне без доступа к сети при каждом изменении содержимого; чтобы снять его заново, выберите «Обновить превью» на плитке или в меню страницы.

## Действия страницы

Страница может попросить выполнить действие — обратиться к одному из ваших источников или запустить скрипт из рабочего пространства. Ничего не выполняется без вашего одобрения: страница спрашивает, когда вы нажимаете её кнопку, а приложение показывает, что именно будет выполнено (для скрипта — путь и отпечаток его содержимого). Одобрение хранится в приложении 30 дней и только для этой версии страницы; если страница или скрипт изменились, приложение спросит снова. Любое одобрение можно убрать в меню страницы **⋯** → **Разрешённые действия**. Каждое действие записывается в журнал приложения.

## Плановое обновление

Страница может обновлять свои данные по расписанию — без сессии агента и без токенов: агент задаёт странице скрипт обновления и расписание cron из пяти полей (не чаще раза в 5 минут), а приложение хранит скрипт рядом со страницей и запускает его через Bun. Полоса над страницей показывает расписание и состояние скрипта: **Ждёт вашего одобрения**, **Одобрено**, **Скрипт изменён после одобрения**, **Приостановлено**, **Выполняется…** или **Скрипт недоступен** (задайте обновление заново через агента).

- **Ничего не запускается без вашего одобрения.** **Проверить и одобрить** показывает точную командную строку, отпечаток скрипта и весь его текст. Одобрение привязано именно к этим байтам вместе с аргументами и средой запуска: любое изменение скрипта — агентом или вручную — останавливает обновление, пока вы не одобрите его снова. Изменение одного только расписания одобрение сохраняет.
- **Запустить сейчас** запускает одобренное обновление сразу; пока запуск не закончится, полоса показывает **Выполняется…**. Неудачный запуск показывает ошибку над страницей.
- **Обновление, которое не одобрено или чей скрипт изменился, не ставится в расписание** — полоса об этом говорит, а в истории автоматизаций записи о нём нет. Политика организации, выключающая локальные автоматизации, останавливает и обновления страниц. Если скрипт изменится между проверкой приложения и плановым запуском, этот запуск отклоняется, и история автоматизаций записывает его с причиной. Отказ **Запустить сейчас** объясняется в уведомлении.
- Скрипт выполняется на вашем компьютере из папки рабочего пространства, с доступом к сети и без секретов в окружении.

## Агенты и страницы

Агенты работают со страницами через шесть инструментов — list_pages, get_page, create_page, update_page, write_page_data и delete_page — в Pi, Claude и Codex (в Codex — через свою связь с сессией). Удаление страницы всегда сначала спрашивает вас, в любом режиме разрешений.

## Публикация

Кнопка **Поделиться** на странице публикует копию только для просмотра во внутренний сервис артефактов компании — см. [Публикация страниц](../go-further/publishing-pages) и [Общий доступ](../go-further/sharing).

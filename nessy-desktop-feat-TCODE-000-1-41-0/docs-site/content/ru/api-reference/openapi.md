# Справочник OpenAPI

Nessy Desktop v1 не публикует спецификацию OpenAPI. Desktop app, CLI и
headless server общаются через внутренний WebSocket RPC-канал, форма которого
может меняться между релизами, поэтому он намеренно не документируется как
публичный API. Если в будущем появится стабильный публичный API, его
спецификация будет размещена на этой странице.

Пока поддерживаемые точки интеграции такие:

- [CLI Reference](../reference/cli) — команды для скриптов против локального
  или удаленного server.
- [API Sources](../sources/apis/overview) — как агент вызывает внешние REST API,
  которые вы подключаете.
- [Config File](../reference/config/config-file) — форматы файлов на диске в
  `~/.nessy-agent`.

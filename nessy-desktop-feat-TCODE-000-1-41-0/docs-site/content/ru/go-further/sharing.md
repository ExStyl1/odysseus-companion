# Общий доступ

Поделиться чатом можно из его меню (**Поделиться**) или кнопкой в заголовке чата. Сначала Nessy показывает карточку подтверждения: что попадёт на страницу, сколько секретов скрыто и путей сокращено, когда истечёт ссылка (через 7 дней), и предпросмотр ровно той страницы, которая будет отправлена. Пока вы не подтвердите, ничего не отправляется.

## Что публикуется

- Чат как есть: ваши сообщения и ответы агента, вызовы инструментов с входными данными и показанным результатом, рассуждения. Блоки инструментов и рассуждения свёрнуты.
- Пути внутри проекта становятся относительными (`src/app.ts`), остальные абсолютные пути — `…/имя`. Домашняя папка и имя учётной записи не попадают на страницу.
- Известные форматы секретов (JWT, токены `ory_…`, заголовки `Bearer`, номера карт, приватные ключи и остальные правила проверки вывода инструментов) заменяются на `[REDACTED:<правило>]`. Закодированные и произвольные секреты проверка не находит — посмотрите предпросмотр перед подтверждением.

## Куда

Страница публикуется в t-artifacts от имени вашего аккаунта dp, поэтому dp должен быть авторизован. Открыть страницу может любой, у кого есть ссылка; другой защиты доступа нет. Опубликованные чаты видны в **Настройки → Рабочее пространство → Опубликованные страницы** с пометкой «Чат»; там их можно продлить или удалить.

## Обновить и закрыть доступ

- **Опубликовано → Обновить общий доступ** отправляет чат в текущем виде по той же ссылке (снова с карточкой). Срок действия не меняется.
- **Опубликовано → Закрыть доступ** удаляет страницу. Если удалить сейчас не получается (dp не авторизован, нет сети), удаление сохраняется и повторяется из «Опубликованных страниц».
- При удалении опубликованного чата Nessy спрашивает, закрыть ли и доступ. **Удалить, оставить ссылку** оставляет страницу открытой до истечения срока.

Удаление страницы не отзывает копии, которые читатели уже сохранили.

## Страницы

Откройте страницу и нажмите **Поделиться**, чтобы опубликовать копию только для просмотра во внутреннем сервисе артефактов компании (t-artifacts). Перед отправкой Nessy показывает, что именно будет опубликовано: кто сможет открыть, срок, размер, результат проверки и предпросмотр с отключёнными скриптами. Данные страницы остаются локальными, пока вы не включите **Включить текущий снимок данных**. Копия доступна всем, у кого есть ссылка, 7 дней; продлить или удалить её можно в **Настройки → Рабочее пространство → Опубликованные страницы**. **Опубликовать последнюю версию** обновляет ту же ссылку, **Снять с публикации** закрывает её. Удаление опубликованной страницы сначала снимает её копию. Страницу, которой разрешено запускать скрипт на вашем компьютере, опубликовать нельзя; страницу с одобренными действиями можно опубликовать только после подтверждения, что читатели получат копию только для просмотра. Публичный сервис обмена Craft в Nessy не входит.

Что отправляет публикация и как устроены ссылки — см. [Публикация страниц](./publishing-pages).

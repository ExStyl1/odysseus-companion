# Темы

Themes задают color palette, которую использует Nessy Desktop. Каждая theme defined against small set of semantic colors instead of per-component overrides, so light mode, dark mode and custom palettes stay predictable.

## Switching Themes

Измените theme в **Settings → Appearance**. Choice applies immediately, and workspace can override app default with its own theme (см. [workspaces](workspaces)).

## Guidelines

- Keep contrast high for session lists, code blocks and tool output — это читают чаще всего.
- Check both light and dark appearances after change.
- Avoid palettes that wash out status or permission colors, since those carry meaning.

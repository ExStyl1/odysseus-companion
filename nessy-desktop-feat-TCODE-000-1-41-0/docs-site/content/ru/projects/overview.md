# Проекты

Проект собирает сессии и страницы одного направления — сервиса, который вы ведёте, длинного исследования, команды — и несёт контекст, который получает каждая привязанная к нему сессия. Проекты перечислены в боковой панели, после **Источников**.

## Страница проекта

Проект открывается из раздела **Проекты** боковой панели (после **Источников**). У страницы проекта три вкладки: **Сессии**, **Файлы** и **Настройки**. У проекта может быть папка: она выбирается через выбор папки и показывается со своим статусом доверия.

## Привязка сессий

Сессия привязывается к проекту из меню сессии: **Проекты** выбирает проект, к которому она относится. Привязка меняет то, что получает агент (см. «Контекст проекта» ниже), и место сессии в отфильтрованных списках.

## Работа проекта в списках

- В списке сессий **Фильтр → Проекты** оставляет сессии проекта, а **Группировка → Проект** собирает их вместе.
- **Настройки → Внешний вид → Цвет проекта в списке** выделяет строки проекта: **Только полоса** или **Полоса и подсветка**.

## Страницы в проекте

Библиотека страниц фильтруется по проекту, а **Перенести в проект** перемещает страницу между проектами. См. [Страницы](../pages/overview).

## Контекст проекта

Если сессия привязана к проекту, агент получает название, описание и подробности проекта в начале разговора и снова при каждом их изменении. Этот текст пишет сам Nessy (`projects/<slug>/context.md`) и перед каждым ходом сверяет его с журналом одобрений, поэтому правка этого файла в обход приложения заменяется копией приложения. У проекта без папки есть и память проекта, которая приходит вместе с этим контекстом, — см. [Память проекта](#память-проекта). Проект с папкой вместо этого использует `.nessy-agent/MEMORY.md` своей папки.

## Память проекта

Проект без папки хранит файл памяти `MEMORY.md` рядом со своими настройками (`projects/<slug>/MEMORY.md` в рабочем пространстве). Каждая сессия, привязанная к проекту, получает его вместе с контекстом проекта, а изменение файла доходит до следующего хода. Записывайте туда то, что должно пережить один разговор: решение, договорённость, подводный камень, предпочтение.

Сессии дополняют файл, но не переписывают его:

- Агент добавляет заметку инструментом `project_memory_append`. Заметка длиной до 4000 символов дописывается в конец файла под заголовком с датой, временем и названием сессии, а остальное в файле не меняется. Если две сессии одного проекта добавляют заметки одновременно, сохраняются обе.
- Агенту сказано никогда не переписывать `MEMORY.md` своими инструментами работы с файлами: другие сессии дописывают заметки, пока он работает, а его копия — лишь снимок; чтобы исправить заметку, он дописывает исправление.
- В сессии, не привязанной к проекту, инструмент отказывает.
- Инструмент одинаков в Pi, Claude Code и Codex.

Длинная память сокращается для агента примерно до 5000 токенов: сохраняются начало (30 %) и конец (70 %), а на месте пропущенной середины стоит пометка, поэтому самые новые заметки — они в конце — доходят всегда. Сам файл не сокращается, и вы можете править его сами в любой момент.

У проекта с папкой отдельной памяти проекта нет: его память — `.nessy-agent/MEMORY.md` самой папки.

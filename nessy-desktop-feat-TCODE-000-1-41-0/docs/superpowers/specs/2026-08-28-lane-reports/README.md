# Lane reports, preserved 2026-08-28

These are the full reports of the implementation and survey lanes that executed
`docs/superpowers/plans/2026-08-22-runtime-parity-closure.md`. They lived in a session
scratchpad, which is temporary; several tracker rows cite measurements that exist in detail
only here.

**Why they are committed rather than summarised.** The plan closes on the owner's stopping
rule — coverage of the governing documentation corpus — and deliberately defers a maintenance
class and a residual survey population to a second iteration. That deferral is only honest if
the deferred work is still actionable later, and a row note is a summary: the reproductions,
the blast-radius numbers, the rejected alternatives and the per-key citations are here.

**Read them as evidence, not as instructions.** Each was written by a lane at a moment in a
moving tree; several were corrected by later measurement, and the tracker row is authoritative
where the two disagree. Three surveys measured this plan's own recorded counts as wrong at
32%, 74% and 67%, so treat any number here as a claim with a date on it.

**The two sweep triages are separate files**, committed earlier and larger:
`2026-08-28-claude-sweep-triage.md` (378 findings, 328 citations) and
`2026-08-28-codex-sweep-triage.md` (65 entries).

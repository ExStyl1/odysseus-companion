## Owner items (to the sitting, not to a lane)

- **Flip `SEATBELT_TESTING_WILDCARD` back to false, or keep it and say so** — Twice-reaffirmed owner decision (2026-07-21, 2026-07-29) and a product posture — it changes what testers experience. The lane brings a measured cost table from a real darwin rig (writes outside cwd, ~/.ssh, pbpaste, dig, git over TLS, keychain) with the strict-branch positive control, plus the reachable-state note that a managed floor forces it on today, and the three-runtime divergence (nothing contained on Pi/claude, real containment on session-tools, `(deny default)` on codex). ESCALATION TRIGGER: if the docblock's claim that writes and `~/.ssh` are contained by other machinery fails to reproduce, this stops being an owner-queue item and becomes a shipped exposure.
- **User-scope `env` block: apply it, or refuse it permanently — four questions, restated against HEAD** — (1) Containment is now a two-option question, not three: the OS-sandbox route is foreclosed by the 2026-08-12/13 standing decision. (2) Refusal must be stated against the FIVE withheld categories, including `execution` (PATH), not the park's stale four. (3) Which rung a user `env` occupies in `proxy-env.ts`'s CA ladder is a choice, not a derivation — it sits beside, not under, the recorded decision that nothing a `git clone` can carry may redirect TLS/proxy. (4) LOCAL scope has no recorded refusal while PROJECT scope errors. The code is the cheap half (`parseManagedEnvBlockV1`/`applyManagedEnv` already exist); the decision is the expensive one.
- **Native LSP: supply the missing producer under detect-and-use, or delete the unreachable branch** — The fallback has no producer in production and none in any test, so the branch has never run. (A) is a new product posture — spawning a language server the user did not install in a trusted project — and needs an explicit `isSafeModeEnabled()` gate, since a producer injected through the deps bag bypasses the safe-mode funnel while `SAFE_MODE_SUPPRESSED_SURFACES` already exports `lsp-servers`. (B) stops advertising a native path this tree never had. Claude has no native LSP mechanism to mirror (probed in the vendored SDK: plugin `.lsp.json` only), so (A) is native-first step 3 and must record why 1 and 2 failed. If (B), the one test pinning the dead branch goes red on purpose.
- **TODO/Task tools on claude: opt in with `CLAUDE_CODE_ENABLE_TODO_TOOLS`, or accept the withdrawal and price it** — The SDK bump we already shipped model-gates TaskCreate/Get/Update/List and TodoWrite on Opus 4.8 / Sonnet 5 and later — our own DEFAULT_MODEL is an exact threshold match, and the remote escape hatch is closed by our nonessential-traffic env. Opting in keeps the switch cost at zero at the stated context price; accepting it means a real cost row and a user-visible statement. Either way the switch-cost rejection built on a `.d.ts` union member must be replaced with the `isEnabled`-derived reading.
- **WebFetch domain preflight: leave it, disable it, or disable it paired with a host-supplied domain allowlist** — The check sends every WebFetch hostname to a hardcoded `api.anthropic.com` endpoint as a query parameter, runs regardless of provider, and is unaffected by the nonessential-traffic switch. Native-first gives three options, not two — the runtime ships both `WebFetch(domain:…)` rules and `sandbox.network.allowedDomains`, both of which this repo already parses, and the page itself prescribes pairing. Pi and codex run no such preflight, so whichever is chosen the residual difference needs one disclosure row.
- **Scheduling: whether the model-target egress work is pulled into the parity plan** — Every row of the source plan is ⏳ and it states it executes AFTER the parity plan closes, with a mandatory re-anchor pass. The engineering is real at HEAD either way; pulling it forward is a scheduling decision, not a discovery. Note that one of its own design collisions (restricted host vs the BYO card's default endpoint) must be settled before the predicate is written, and that its live-network probe series cannot run offline.
- **codex teardown: keep the switch-refusing throw, or make a teardown failure non-fatal to the runtime switch** — `codex-agent.ts` states the rejection is deliberate — it is the contract SessionManager awaits, and totality there means no step can cancel another, not that failures are swallowed. Downgrading it to a warning would let the switch proceed over a possibly-leaked child process and a possibly-undeleted per-session CODEX_HOME. Put it to the owner rather than slipping it in; the lane's job first is to name WHICH of the five steps fails, since three of them look structurally unable to reject.

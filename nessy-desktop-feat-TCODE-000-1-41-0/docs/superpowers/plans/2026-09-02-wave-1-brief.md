- **Evidence.** Claude: the page IS the contract — cite `https://code.claude.com/docs/en/<page>.md#<section>`
  plus the verbatim sentence, never a line number; verify anchors by `curl`ing the page WITHOUT `.md`
  and grepping `id="…"`. Codex: `github.com/openai/codex` at tag **`rust-v0.148.0`** or the shipped
  binary is **strong**; a docs page alone is **weak — intent, not behaviour**; read codex docs as the
  `.md` twin (their rendered pages are client-side). Codex hook events are **eleven**
  (`packages/codex-protocol/generated/v2/HookEventName.ts`); the managed-requirements wire type has
  **25** fields, three `#[experimental]`; the generated protocol under-reports 47 methods. The vendored
  Claude SDK is `0.3.223` / `claudeCodeVersion 2.1.223` — say which side a guard came from when the
  bundle and the page disagree.
- **Native-first, then the host makes the residue uniform or HONEST.** Before building, state what
  you found when you asked whether the runtime already has the mechanism. A native mechanism adopted
  without a switch verdict is a new silent divergence, not a closed gap.
- **Read, do not invent.** Where the documentation is silent: decide, TRANSPARENT (a diagnostic, a
  setting, or a comment naming the choice) and SIMPLE. Never decide a product posture quietly.
- **Absence needs a positive control on the same rig**, and an identifier probe is systematically
  biased toward false absence — drive the behaviour. `grep -a` for any absence claim; `:(glob)` on any
  `**` pathspec to git.
- **In-place fix rule (owner 2026-08-31):** a residue in your zone, under ~30 lines, changing no
  contract and no posture, may be fixed in place instead of rowed — and MUST be listed in your report
  and your commit body. Unmentioned in-place fixes are worse than the row they replaced.
- **New findings:** a row only if a tool call passes through it, or it changes what the model is told /
  sees / may do, or it differs across runtimes at a switch; a control that silently stops controlling
  is always in. Otherwise append to `docs/superpowers/specs/2026-08-28-out-of-scope-register.md`
  (read its header) and list under `## Out of scope` in your report.
- **Git.** Commit ONLY your own files by explicit path; never `git add -A`, bare `git commit`,
  `--amend`, `git stash`, `git reset`, `git checkout --`, `git clean`. Both bare and pathspec commits
  have swept neighbours' work here; the only safe form is a pathspec commit of files nobody else
  touches — which is what the zones below guarantee. If a fix needs a file outside your zone, STOP
  and report it.
- **Tests.** `bun scripts/bun-test-lock.ts run --label <lane> -- bun test <paths>` from the repo root
  (a package-cwd run loses config isolation). Read the FILE COUNT, not the pass count — a
  nonexistent path runs the rest silently. Check `docs/superpowers/specs/2026-07-29-known-failing-tests.md`
  before recording a red; while lanes run, attribute a red with a `git worktree` control at your base
  (and a shadow `node_modules`, or the worktree measures the parent). Verify BOTH
  `cd packages/shared && bun run tsc --noEmit` and `cd packages/pi-agent-server && bun run typecheck`
  — DOM-only type names are green in one and red in the other. **Re-break each fix** to prove its test
  catches it; restore by writing the whole file back and checking the hash.

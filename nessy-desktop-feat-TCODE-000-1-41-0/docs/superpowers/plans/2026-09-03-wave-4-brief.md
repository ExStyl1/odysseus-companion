## Shared rules

`docs/superpowers/plans/2026-09-03-wave-3-brief.md` §"Shared rules" in full (which carries the wave-1
and wave-2 rules), plus what wave 3 added, all binding:

- **A backtick inside `git commit -m "…"` is a command under zsh.** Write the message to a file and
  pass `-F <file>`, or single-quote it with no backtick. One commit this week carries a 5 921-line
  message because of this.
- **A lane that adds locale keys commits them FIRST, alone**, and says in its report which commit
  carries them — the *commit only your keys* rule protects only the sweeper.
- **A caught import failure is not a contained one** — probe imports in a child process; a test that
  `delete`s `process.env.X` mutates the whole run; `mock.module` mutates the imported namespace in
  place, so restore from a spread taken before the mock.
- **Drive, do not read, before rowing an absence** — P3.320 was rowed on a reading of callers and refuted
  by driving the store. An emptiness assertion against a fixture that returns nothing cannot catch a
  projection that returns nothing.
- Everything else as before: pathspec commit in one step with nothing pre-staged; STOP-AND-REPORT with
  patch text outside your zone; declare zone changes before editing; `git status` beside every
  working-tree measurement; the four-part harness rule; `bun scripts/bun-test-lock.ts run --label <lane>`;
  FILE counts; the known-failing register before any red; no real credential in any file; never a real
  home directory as a target of rm/mv. Reports to the session scratchpad as `lane-<lane>-report.md`.

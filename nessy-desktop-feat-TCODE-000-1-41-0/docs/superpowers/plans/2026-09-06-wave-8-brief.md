## Standing rules (restated from `docs/superpowers/plans/2026-09-05-wave-7-brief.md` §"Standing rules")

Wave 7's rules apply in full and they carry every earlier wave's. Restated because each has already cost a real
measurement, with the wave-8 additions marked **NEW**:

1. **Commit per row, or per coherent bundle of rows inside one lane** — not one commit per lane. The subject is
   the **row's own title**, in the plan's voice (`<type>(<scope>): <sentence>`). A bundle commit names every row
   it lands.
2. **Lanes do NOT edit the plan.** The tracker (`docs/superpowers/plans/2026-08-22-runtime-parity-closure.md`)
   is written by the **controller**, which pins glyph, commit sha and note from the lane reports. A lane that
   wants a row's note changed says so in its report.
3. **No `Co-Authored-By` trailers.** Ever, in any project.
4. **Commit message via a file and `-F`.** `git commit -m "…"` with backticks is command-substituted by zsh —
   house style quotes identifiers in backticks, and one lane's message swallowed a `` git ls-files `` span into
   a 5 921-line commit (measured 2026-09-03). Write the message to a file and pass `-F <file>`; never nest a
   backtick inside `-m`.
5. **Commit ONLY in the atomic form `git commit -F <msg> -- <pathspec>`** (wave rule, measured by W6-d and
   confirmed by a second lane on 2026-09-06). A bare `git add` followed by `git commit` in this shared tree
   **commits another lane's staged index** — three files a lane had staged were swept into a concurrent lane's
   `i18n(...)` commit whose own message said "committed alone"; nothing was lost, the row→sha mapping was.
   Forbidden outright: `git add -A`, `git commit -a`, `git stash`, and `git commit --amend` (an amend in this
   tree once rewrote a sibling lane's commit message).
6. **`git commit <pathspec>` takes the file's WORKING-TREE state, not your hunks.** This is the whole reason
   the zones below are file-exclusive. If you need a file another lane owns, **hand the patch to that lane**
   (patch text in your report); do not edit it. Declare any zone change before editing; `git status` beside
   every working-tree measurement.
7. **Report file `scratchpad/lane-W8-<x>-report.md`, updated after EVERY row**, not at the end. It carries: the
   row-by-row verdict; the native-mechanism answer per row; every in-zone residue fix; every hand-off patch for
   a file another lane owns; and every new plan row proposed, with the reason. The controller reads only this
   file — a finding that is not in it does not reach the plan.
8. **Implementation-first verification budget.** During the loop: focused tests for the changed behaviour, the
   affected package's typecheck, the directly affected contract tests, scope checks, `git diff --check`.
   Nothing else. The full gate runs once at the wave boundary on the final tree. Read the **FILE COUNT** of
   every `bun test` run, never the pass count — `bun test` given a path that does not exist runs the rest and
   says nothing. Check `docs/superpowers/specs/2026-07-29-known-failing-tests.md` before recording a new red.
9. **Findings become plan rows AT CONFIRMATION** (owner rule 2026-08-23, amended 2026-08-31). A lane MAY fix a
   residue **in place** if it is **in-zone, under ~30 lines and changes no contract** — and must report every
   such fix. Everything else is reported for the controller to insert **in sorted position**
   (`python3 scripts/sort-plan-tracker.py <plan>`; `--check` reports drift without writing).
10. **Read, do not invent** (owner rule 2026-08-28). Nearest documented solution → reference implementation →
    ask the owner → invent, in that order. *"I could not find it documented"* is a finding to record, not a
    licence to invent — write what you searched. For **codex the SOURCE outranks the page**
    (`github.com/openai/codex`, `rust-v0.148.0` is what the shipped binary is built from); for **claude the
    documentation IS the contract**, and the codex caution about pages must not be imported there. Cite
    `page.md#<section>` plus the verbatim sentence, never a line number, and derive an anchor by `curl`-ing the
    page WITHOUT `.md` and grepping `id="…"` — right for `code.claude.com`, WRONG for `learn.chatgpt.com`
    (read the `.md` there).
11. **Native-first, and the host is the smooth seam** (owner rule 2026-08-28). Per row: does the runtime
    already have its own mechanism? (1) enable and configure it; (2) else can the host supply it uniformly for
    all three; (3) else build per runtime and write down why 1 and 2 failed. Most rows already carry a *"Native
    mechanism, verbatim"* clause: **confirm or correct it at HEAD**, do not re-derive it. **A native mechanism
    adopted without a switch verdict is a new silent divergence, not a closed gap.**
12. **Re-measure at HEAD before building.** Every row here was born from a sweep measurement; a row that turns
    out closed at HEAD is a result to pin, not a reason to build. This matters more in wave 8 than in any
    earlier wave: 200 rows are held by lanes that do not pin their own work.
13. **NEW — the owner's 2026-09-05 principle is the tie-break, and it is a STANDING RULE.** «делай по
    рекомендации, чтобы было максимально проще по интеграции, меньше кода если это возможно, так как рантаймы
    мы будем часто обновлять.» Take the controller recommendation; make the integration as simple as possible

### How the zones were derived, and what the derivation cannot see

Say this plainly, because a check that looks stronger than its input is the worst kind. **The write set of a
row here is a PROXY**: the files named inside its `done_means` and its controller-decision line, union the file
rezone.md hands the row to, resolved against `git ls-files`. Doc paths, generated schemas and upstream pages
are dropped. **What the proxy cannot see is a row that turns out to need a third file** — that is what rule 6's
*declare-before-editing* clause is for, and a lane that hits it says so in its report **before** touching the
file. The check at the bottom proves the DECLARED zones are pairwise disjoint inside each group; it does not
prove the declaration is complete, and no script can.

**Why 22 lanes and not 14.** 143 build rows do not fit fourteen lanes at four-to-eight rows each (14 × 8 =
112). The wave uses **W8-a … W8-w, skipping `W8-p`** — `-p` is reserved by convention for a packaged sitting,
and wave 8 has none of its own (W6-p and W7-p hold it). Lanes carrying an **L** row are deliberately short.

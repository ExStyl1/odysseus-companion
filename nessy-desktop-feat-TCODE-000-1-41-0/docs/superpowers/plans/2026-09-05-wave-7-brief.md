## Standing rules (restated from `docs/superpowers/plans/2026-09-05-wave-6-brief.md` §"Standing rules")

Wave 6's rules apply in full and they carry every earlier wave's. Restated because each has already
cost a real measurement, with the wave-7 additions marked **NEW**:

1. **Commit per row, or per coherent bundle of rows inside one lane** — not one commit per lane. The
   subject is the **row's own title**, in the plan's voice (`<type>(<scope>): <sentence>`). A bundle
   commit names every row it lands.
2. **NEW — lanes do NOT edit the plan.** The tracker
   (`docs/superpowers/plans/2026-08-22-runtime-parity-closure.md`) is written by the **controller**,
   which pins glyph, commit sha and note from the lane reports. This inverts wave 6's rule 1: 301 rows
   over 22 lanes on one file is a collision generator, and `git commit <pathspec>` takes the file's
   working-tree state, not your hunks. A lane that wants a row's note changed says so in its report.
3. **No `Co-Authored-By` trailers.** Ever, in any project.
4. **Commit message via a file and `-F`.** `git commit -m "…"` with backticks is command-substituted
   by zsh — house style quotes identifiers in backticks, and one lane's message swallowed a
   `` git ls-files `` span into a 5 921-line commit (measured 2026-09-03). Write the message to a file
   and pass `-F <file>`; never nest a backtick inside `-m`.
5. **`git commit <pathspec>` takes the file's WORKING-TREE state, not your hunks.** This is the whole
   reason the zones below are file-exclusive. If you need a file another lane owns, **hand the patch to
   that lane** (patch text in your report); do not edit it. Declare any zone change before editing;
   `git status` beside every working-tree measurement.
6. **NEW — report file `scratchpad/lane-W7-<x>-report.md`, updated after EVERY row**, not at the end.
   It carries: the row-by-row verdict; the native-mechanism answer per row; every in-zone residue fix;
   every hand-off patch for a file another lane owns; and every new plan row proposed, with the reason.
   The controller reads only this file — a finding that is not in it does not reach the plan.
7. **Implementation-first verification budget.** During the loop: focused tests for the changed
   behaviour, the affected package's typecheck, the directly affected contract tests, scope checks,
   `git diff --check`. Nothing else. The full gate runs once at the wave boundary on the final tree.
   Read the **FILE COUNT** of every `bun test` run, never the pass count — `bun test` given a path
   that does not exist runs the rest and says nothing. Check
   `docs/superpowers/specs/2026-07-29-known-failing-tests.md` before recording a new red.
8. **Findings become plan rows AT CONFIRMATION** (owner rule 2026-08-23, amended 2026-08-31). A lane
   MAY fix a residue **in place** if it is **in-zone, under ~30 lines and changes no contract** — and
   must report every such fix. Everything else is reported for the controller to insert **in sorted
   position** (`python3 scripts/sort-plan-tracker.py <plan>`; `--check` reports drift without writing).
9. **Read, do not invent** (owner rule 2026-08-28). Nearest documented solution → reference
   implementation → ask the owner → invent, in that order. *"I could not find it documented"* is a
   finding to record, not a licence to invent — write what you searched. For **codex the SOURCE

### How the zones were derived, and why the mechanical check is only as good as the derivation

Say this plainly, because a check that looks stronger than its input is the worst kind:

**The write set of a row is a PROXY, derived by script from the row's own citations** — the seam files
it cites with a line reference, ranked by how often that row cites them, capped at the top two, plus
any file named inside its `done_means`. Doc paths and `node_modules` are dropped; the eleven upstream
Claude/codex pages are dropped; `**` globs are dropped. Reproduce it:

```sh
grep -a '^| P6\.\(19[1-9]\|[2-4][0-9][0-9]\) ' docs/superpowers/plans/2026-08-22-runtime-parity-closure.md
# per row: collect `path.ts:NNN` citations, rank by in-row count, take the top two,
# union with every tracked path named inside **done_means:**, resolve basenames against `git ls-files`
```

Measured over the 301 rows: **1.9 files per row**, 258 distinct files, 18 rows citing no seam at all
(their write set falls back to their first resolved citation). The four hot spots by write-set
frequency are `claude-agent.ts` **36**, `SessionManager.ts` **31**, `codex-agent.ts` **17**,
`config-writer.ts` **16** — which is why rule 12 exists and why the last three groups are small.

**What the proxy cannot see:** a row that turns out to need a third file. That is what rule 5's
*declare-before-editing* clause is for, and a lane that hits it says so in its report before touching
the file. The check below proves the DECLARED zones are disjoint; it does not prove the declaration is
complete, and no script can.

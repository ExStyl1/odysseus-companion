## Standing rules

Wave 8's fifteen apply in full and carry every earlier wave's. Restated in one line each — each has already
cost a real measurement — followed by **seven new ones**, every one of which cost a red in wave 8.

1. **One commit per row**, or per coherent bundle inside one lane; subject is the row's own title in the plan's
   voice (`<type>(<scope>): <sentence>`), and a bundle names every row it lands.
2. **Lanes do NOT edit the plan.** The controller pins glyph, sha and note from the lane reports. Ask in the
   report; never write the tracker.
3. **No `Co-Authored-By` and no attribution trailer**, ever, in any project.
4. **Commit message via a file and `-F`** — `git commit -m` with backticks is command-substituted by zsh, and
   house style quotes identifiers in backticks.
5. **Commit ONLY as `git commit -F <msg> -- <pathspec>`.** Forbidden outright: `git add -A`, `git commit -a`,
   `git stash`, `git commit --amend`.
6. **`git commit <pathspec>` takes the file's WORKING-TREE state, not your hunks** — which is the whole reason
   the zones are file-exclusive. Need another lane's file? Hand it the patch in your report.
7. **Report file `scratchpad/lane-W9-<x>-report.md`, updated after EVERY row.** The controller reads only this.
8. **Implementation-first verification budget**: focused tests for the changed behaviour, the affected package's
   typecheck, the directly affected contract tests, `git diff --check`. Read the **FILE COUNT** of every
   `bun test` run, never the pass count.
9. **Findings become plan rows at confirmation.** An in-zone residue under ~30 lines that changes no contract
   may be fixed in place — and must be reported. Everything else is a proposed row.
10. **Read, do not invent**: nearest documented solution → reference implementation → record *"not found,
    searched X"* → invent last, with the reason written. Claude: the page IS the contract, cite
    `page.md#<section>` + the verbatim sentence. Codex: the **source** at `rust-v0.148.0`, or the shipped
    binary, outranks the page.
11. **Native-first, and the host is the seam.** Confirm or correct each row's *"Native mechanism"* clause at
    HEAD. A native mechanism adopted without a switch verdict is a new silent divergence, not a closed gap.
12. **Re-measure at HEAD before building.** A row closed at HEAD is a result to report, not a reason to build.

## How the zones were derived, and what the derivation cannot see

Every zone below is the union of the row's verified write set and the file the pause's rezone table hands the
row to, **resolved against `git ls-files` at `c20c6671c`** — not the proxy wave 8 used. Doc paths, generated
schemas and upstream pages stay in the bullets but out of the machine-checked zone line.

Two conventions make the check meaningful, and both are stated rather than hidden:

- **A NEW file is not part of the machine-checked zone.** Several lanes create a new test or a new module in a
  directory another lane also writes into. Those appear in the zone line as prose (no backticks) and the lane
  **declares the exact path in its first report**. Two lanes may create different new files in the same
  `__tests__` directory; neither may touch the other's existing suites.
- **The check proves the DECLARED zones are disjoint, not that the declaration is complete.** A row that turns
  out to need a third file is exactly what rule 6's declare-before-editing clause is for: say so in the report
  **before** touching the file. No script can see that in advance.

## Verification — the counts this brief asserts about itself

The script below reads the plan and **this file**, and proves four things: the open set is 234; every open row
appears in **exactly one** bucket (no duplicate, nothing unknown, nothing unplaced); every lane carries four to
eight rows; and **within each group the declared zones are pairwise disjoint**. It skips fenced code blocks, so
it does not read its own source, and it extracts zone paths **only** from each lane's `**Zone …**` paragraph —
which is why the NEW-file entries there are written as prose (§"How the zones were derived").

````python
import re, itertools, collections
PLAN  = 'docs/superpowers/plans/2026-08-22-runtime-parity-closure.md'
BRIEF = 'docs/superpowers/plans/2026-09-07-wave-9-brief.md'
OPEN  = set('⬜🟨🟧⏸⛔')

plan_open = []
for ln in open(PLAN, encoding='utf-8'):
    if ln.startswith('| P'):
        p = [x.strip() for x in re.split(r'(?<!\\)\|', ln)]
        if len(p) > 4 and p[3] in OPEN:
            plan_open.append(p[1])
plan_set = set(plan_open)

bucket = None; group = None; lane = None; fence = False; in_zone = False
rows = collections.defaultdict(list)      # bucket -> [id]
lane_rows = collections.defaultdict(list) # (group, lane) -> [id]
zones = {}                                # (group, lane) -> [path]
for ln in open(BRIEF, encoding='utf-8'):
    if ln.startswith('```'):
        fence = not fence; continue
    if fence: continue
    m = re.match(r'## ([ABCDE]) — ', ln)
    if m: bucket, group, lane = m.group(1), None, None; continue
    if ln.startswith('## '): bucket = None; continue
    if bucket == 'B' and ln.startswith('### Group '):
        group = ln.split('—')[0].strip('# ').strip(); lane = None; continue
    if bucket == 'B' and ln.startswith('#### W9-'):
        lane = ln.split('—')[0].strip('# ').strip(); in_zone = False; zones.setdefault((group, lane), []); continue
    if bucket == 'B' and lane and ln.startswith('**Zone'):
        in_zone = True
    if in_zone:
        if not ln.strip():
            in_zone = False; continue
        zones[(group, lane)] += re.findall(r'`([^`]+)`', ln); continue
    m = re.match(r'- \*\*(P\d+\.\d+)\*\*', ln)
    if m and bucket:
        rows[bucket].append(m.group(1))
        if bucket == 'B' and lane: lane_rows[(group, lane)].append(m.group(1))

allids = list(itertools.chain.from_iterable(rows[b] for b in 'ABCDE'))
dup     = [i for i, n in collections.Counter(allids).items() if n > 1]
unknown = sorted(set(allids) - plan_set)
missing = sorted(plan_set - set(allids))
big     = [f'{l}={len(r)}' for (g, l), r in lane_rows.items() if not 4 <= len(r) <= 8]

overlaps = []
by_group = collections.defaultdict(list)
for (g, l), z in zones.items(): by_group[g].append((l, set(z)))
for g, lanes in by_group.items():
    for (a, za), (b, zb) in itertools.combinations(lanes, 2):
        if za & zb: overlaps.append(f'{g}: {a} ∩ {b} = {sorted(za & zb)}')

print('plan open rows      :', len(plan_open), '(distinct', len(plan_set), ')')
print('brief bucket counts :', {b: len(rows[b]) for b in 'ABCDE'}, '· sum', len(allids))
print('duplicates          :', dup)
print('ids not open in plan:', unknown)
print('open rows unplaced  :', missing)
print('lanes / rows        :', len(lane_rows), '·', {l: len(r) for (g, l), r in sorted(lane_rows.items())})
print('lanes out of 4..8   :', big)
print('zone paths per lane :', {l: len(z) for (g, l), z in sorted(zones.items())})
print('intra-group overlaps:', overlaps)

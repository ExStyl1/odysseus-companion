**Two kinds of row, and the difference decides what a pass means.**

- 🖐 **live** — a user-visible behaviour. Drive it in a packaged build and observe.
  `electron:dev` runs the host and the Pi subprocess from BUILT bundles, and
  `resolveInterceptorBundlePath` silently starts Pi UNPATCHED when the bundle is

- 🧪 **latent** — the classifier recorded no observable impact. It CANNOT be
  confirmed by clicking; a green live pass here would be meaningless. Confirm it
  by the unit's own test, and record which test.

Force dark theme before any screenshot. Driver: `scripts/cdp/`; product-indexed
cases live in `docs/testing/cdp-live-checklist.md` and a unit that adds a live

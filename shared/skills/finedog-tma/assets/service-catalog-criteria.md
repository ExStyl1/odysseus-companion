# Критерии проверки каталога услуг (Service Catalog)

**Источник:** https://wiki.tcsbank.ru/pages/viewpage.action?pageId=7688897673

## Полные критерии оценки заполненности услуги в Finedog

| Категория | Критерий | Методика оценки | API поле |
|---|---|---|---|
| **Общие требования** | Структура каталога | Соответствует описанию | — |
| **Связи** | Влияющие связи | Во "Влияющих" связях указан хотя бы один юнит типа система/подсистема/компонент | `/v1/units/{id}/relation/from` |
| **Команды** | Дежурная команда разработки | Указана команда разработки | `teamsIds` |
| **Команды** | Команда SRE | Указана команда SRE | `teamsIds` (через кэш команд) |
| **Команды** | Команда Support | Указана команда Support | `teamsIds` (через кэш команд) |
| **О юните** | Описание | Заполнено, не совпадает с названием, >= 20 символов | `description` |
| **О юните** | Мониторинг SLA | Заполнено поле "Мониторинг SLA" | `slaMonitoring` |
| **О юните** | Чат поддержки | Заполнено поле "Чат поддержки" | `supportChat` |
| **О юните** | Документация | Заполнено поле "Документация" | `documentation` |
| **О юните** | Анонсы | Заполнено поле "Анонсы" | `announcements` |
| **Соглашения** | Заполнены соглашения | Есть как минимум одно соглашение | `agreements` |
| **Соглашения** | Заполнены ранбуки | Во всех соглашениях указан ранбук | `agreements[].runbook` |

## Метрика заполненности

**Метрика заполненности отдельного юнита** = (количество выполненных критериев / общее количество критериев) × 100%

**Метрика заполненности каталога услуг** = среднее арифметическое значений метрик заполненности всех юнитов каталога

## Проверка через Finedog API

**Скрипт:** `check-service-catalog.py`

**Алгоритм:**
1. Парсит `docs/metrics/service-catalog.md` и извлекает ID юнитов
2. Для каждого юнита выполняет запрос к Finedog API: `GET /v1/units/{id}`
3. Получает связи юнита: `GET /v1/units/{id}/relation/from`
4. Проверяет все критерии из таблицы выше
5. Генерирует отчёт в `docs/metrics/service-catalog-check-report.md`

**Команда:** `"проверь каталог услуг"`

# План: обзор продукта для комитета

Фикстура для сценария workflow-user-supplied-plan. Это план, который пользователь
составил сам и приносит готовым. Закрывающего слайда в нём нет — намеренно.

## Главное

Мобильный онбординг вышел на плановые показатели за два квартала вместо четырёх.

## Факты

- **F1.** Регистрация занимает 3 минуты против 11 минут год назад — замеры
  продуктовой аналитики.
- **F2.** Доля завершённых регистраций 72 процента — та же выгрузка.
- **F3.** Команда сократилась с девяти человек до шести после стабилизации.

## Слайды

1. Титул: «Онбординг вышел на план за два квартала»
2. Повестка: где были, что сделали, где сейчас
3. Что изменили: три пункта про упрощение шагов
4. Цифры: три показателя рядом ← F1, F2, F3

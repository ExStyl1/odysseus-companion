# Time to Jira

Скилл для автоматического создания задач в Jira на основе обсуждения в Time messenger.

## Быстрый старт

```
Создай задачу в Jira по этому треду: https://time.tbank.ru/tinkoff/pl/abc123def456
```

## Что умеет

### Автоматическое извлечение данных
- Анализ диалога через LLM
- Извлечение проблемы, шагов воспроизведения, ожидаемого поведения
- Определение массовости проблемы и даты появления

### Форматирование для Jira
- Jira wiki markup (не Markdown!)
- {panel} блоки для каждого раздела
- Автоматическая ссылка на исходный тред

### Поддержка проектов
- **INSSRE** (по умолчанию) — инфраструктура, мониторинг, SRE
- **TIGD** — Guidewire, полисы, биллинг
- **TICA** — Claims API

## Рабочий процесс

1. **Извлечение ID треда** из URL Time
2. **Получение треда** через API или от пользователя
3. **Анализ через LLM** — генерация JSON с 7 полями
4. **Валидация JSON** — проверка полноты полей
5. **Уточнение проекта** — INSSRE по умолчанию
6. **Создание задачи** в Jira с wiki markup
7. **Возврат ссылки** пользователю

## Примеры использования

### Стандартное создание задачи
```
Создай задачу в Jira по этому треду: https://time.tbank.ru/tinkoff/pl/abc123def456
```

### В конкретный проект
```
Создай задачу в проект TIGD по этому треду: https://time.tbank.ru/tinkoff/pl/custom123
```

### Если тред недоступен
```
Заведи баг из обсуждения: [пользователь копирует текст вручную]
```

## Выходной формат

1. **Краткое резюме** — что было сделано
2. **Ссылка на задачу** — `https://jira.tcsbank.ru/browse/KEY-123`
3. **Детали** — заголовок, проект, тип задачи
4. **Исходный тред** — ссылка для контекста

## Типы задач

| Тип | Когда использовать |
|-----|-------------------|
| **Bug** | Проблема, ошибка, дефект (по умолчанию) |
| **Task** | Работа по улучшению |
| **Story** | Функциональность для пользователя |

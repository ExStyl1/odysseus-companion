# Task Bars: бары задач, буферы, дедлайн

## Бар задачи

- Прямоугольник со скруглением (RectangleRounded), **все 4 угла** скруглены (`strokeRadius`
  topLeft/topRight/bottomRight/bottomLeft = 50), высота **~40px**.
- **Фон = цвет потока/строки.** **Не используй красные тона** для задач/потоков (например `#F4B8B8`)
  — они зарезервированы под обводку Bug и дедлайны.
- **Обводка по типу** (если передан `type`): красная `#ff7a91` (Bug), синяя `#3b82f6` (Epic);
  без `type` — нейтральная.

### Текст — два абзаца

- **1-я строка:** ключ-ссылка + **тип (жирным) и статус** в квадратных скобках:
  `<a href="{link}" rel="noopener noreferrer" target="_blank">{key}</a> [<strong>{type}</strong>: {status}]`
- **2-я строка:** заголовок (`title`).

Полный пример (для Tracker):
```html
<p><a href="https://tracker.t-tech.team/task/TRACK-1534" rel="noopener noreferrer" target="_blank">TRACK-1534</a> [<strong>Epic</strong>: Backlog]</p><p>Удаление спринтов</p>
```

Шаблоны ссылки (если `link` не передан — по `source` конкретной задачи):
- Tracker → `https://tracker.t-tech.team/task/{key}`
- jira → `https://jira.tcsbank.ru/browse/{key}`
- jira2 → `https://jira2.tcsbank.ru/browse/{key}`
- jira3 → `https://jira3.tcsbank.ru/browse/{key}`

Правила текста:
- если `type` нет — скобки `[{status}]`; если `status` нет — `[<strong>{type}</strong>]`;
  если обоих нет — 1-я строка без скобок; если `title` нет — 2-я строка опускается;
  без `link` — просто `{key}` без `<a>`.
- **Плейсхолдер-режим:** 1-я строка — `ID-N` без ссылки и скобок, 2-я — `title`.

### Стиль текста бара (позиционирование внутри бара)
Текст внутри бара выравнивается **по левому краю по горизонтали** и **по центру по вертикали**:
`textAlign "s"` (start/слева), `textVerticalAlign "m"` (middle/по центру).

```json
"textAlign": "s",
"textVerticalAlign": "m",
"textColor": "#3A3A3A",
"textFontFamily": "Oswald, Segoe UI Emoji",
"textFontSize": 14
```

- `textAlign "s"` — текст прижат к **левому краю** бара, а не по центру: так длинный `title` не
  обрезается с обеих сторон и ключ/статус читаются сразу от начала бара.
- `textVerticalAlign "m"` — текст **вертикально по центру** бара (две строки выровнены по середине
  высоты 40px).
- Не задавай `textAlign "m"` (центр) для текста бара — при длинном `title` центр-выравнивание
  приводит к обрезке текста с обеих сторон.

### Позиция и размер
- `x = 440 + start_day × 20`, где `start_day` — число дней от якоря до `planned_start`.
- **ширина** = `(planned_end − planned_start + 1) × 20` (включает день старта).
- **Точные даты, без сдвигов:** рисуй ровно в переданных `planned_start`/`planned_end`. Даты **не
  выравниваются**.
- Если задачи одного потока **перекрываются** по времени — размести перекрывающиеся бары на
  **дополнительных строках того же потока** (стек), X (даты) при этом **не меняются**.

## Дедлайн (опц.)

Если у задачи есть `deadline` — отдельный кружок (`shape "5"`, ~20px):
- Горизонтально **центр кружка = центр дня дедлайна**: `x = 440 + deadline_day × 20`, ширина 20.
- Вертикально **центр кружка = середина бара**: `y = bar.y + (bar.height/2) − кружок/2`
  (при высоте 40 и кружке 20 → `y = bar.y + 10`).
- Стиль: фон `#FFBDB2`, обводка `#FF6347`, `strokeWidth 2`, текст `<p></p>`.

## Буферное время (визуальный блок)

Прямоугольник со **штрихованной обводкой** (`strokeStyle: dashed`):
- **Буфер блока** (`kind: block`): фон `#fff7cc`, обводка янтарная `#eab308`, подпись «Буфер 60%»
  (или переданный `label`).
- **Завершающий буфер** (`kind: finish`): фон `#ffe4e6`, обводка красная `#f43f5e`, подпись
  «Завершение +10%» (или переданный `label`).

Позиция/ширина по `from`/`to` так же, как бары: `x = 440 + from_day × 20`,
`width = (to_day − from_day + 1) × 20`. Навык **не вычисляет** размер буфера — рисует по готовым
датам.

## Подпись строки/потока

Слева от строк — текст-метка с названием потока/группы (например `a.zagovalko` или `T-Soft`), с
опциональной свободой по дате (например `· своб. +1д`), если передана.

**Цвет подписи = тёмный тон цвета фона баров этого потока** (а не нейтральный `#3A3A3A`). Возьми
цвет фона потока и примени его затемнённый оттенок, чтобы подпись визуально ассоциировалась с
группой. Примеры пар «фон потока → цвет подписи»:
- `#d8e4f0` (светло-синий) → `#2b5d8a`
- `#cfe8e0` (светло-бирюзовый) → `#2f6b5a`
- `#e2e0f0` (светло-сиреневый) → `#4c4a78`
- `#e8e0d3` (светло-бежевый) → `#6b5a3f`

Не оставляй все подписи одним серым цветом — это нарушение визуальной связки группа↔цвет.

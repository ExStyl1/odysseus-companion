# Layout: масштаб, координаты, ось и сетка

## Масштаб и координаты

- **20px = 1 день**; неделя = 7 дней = **140px**.
- Левая граница календаря (день 0, x-координата) = **x = 440**.
- День `d` от якоря → `x = 440 + d × 20`.
- Якорь (день 0) = минимальная дата среди задач; включая буферы и концы связей. Если задач нет —
  берётся переданный период.
- Ось покрывает весь горизонт (от минимальной до максимальной даты).
- Координаты баров кратны 20px и прилегают — проверяй границы.

## Ось времени (три уровня, сверху вниз)

Ось — прилегающие прямоугольники. Все со **скруглением углов 20%** (`strokeRadius` = 20 на все углы).

- **Кварталы:** `Q4'26 (54 р.д.)` — текст + число рабочих дней в скобках. Одинаковый квартал
  разных лет — один цвет (Q1 всегда один, Q2 — свой и т.д.).
- **Месяцы:** полными названиями — `Октябрь (12 р.д.)`, `Ноябрь (20 р.д.)`, … Месяц берёт **тот же
  цвет фона и текста, что и его квартал**.
- **Недели:** скруглённые прямоугольники с номером — `W42`, `W43`, …. Номер — **ISO-номер недели
  в году** (не сквозная нумерация от начала оси). Пример для 2026: `W20, W21, …, W53`.

## Вертикальный зазор

Между нижним краем самого нижнего ряда оси (недель) и верхним краем **самой верхней строки задач**
должно быть **20px** по высоте. Строки задач ниже — фиксированным шагом
(высота бара ~40px + межстрочный зазор).

## Линии-разделители недель

У **каждой** недели — **одна** вертикальная линия на границе с последующей неделей, идущая вниз на
**всю высоту RoadMap** (+ запас). `start` прикреплён к элементу недели (`boundToId`, справа —
`position x:0, y:0.5`), `end` — абсолютная точка внизу (без `boundToId`).

Стиль: `strokeColor "#CCCCCC"`, `strokeStyle "do"` (пунктир), `strokeWidth 2`, `lineEndTip 0`,
`lineStartTip 0`, `lineType "a"`, `lineStrokesCount 1`; `size.width ≈ 0`,
`size.height = высота RoadMap + запас`.

```json
{
  "type": "line", "schema": 1,
  "size": { "width": 0, "height": 1349 },
  "position": { "x": 580, "y": 173 },
  "points": [],
  "tipPoints": {
    "start": { "boundToId": "<id недели>", "position": { "x": 0, "y": 0.5 } },
    "end":   { "position": { "x": 580, "y": 1522 } }
  },
  "style": {
    "fillColor": "transparent", "fillStyle": "s",
    "strokeColor": "#CCCCCC", "strokeStyle": "do", "strokeWidth": 2,
    "lineEndTip": 0, "lineStartTip": 0, "lineType": "a", "lineStrokesCount": 1
  }
}
```

## Выделение нерабочих дней — только праздники

**Это обязательный шаг (не пропускай).** Прямоугольником подсвечиваются **только** нерабочие дни,
которые **не** являются обычными выходными (сб/вс), т.е. **государственные праздники РФ** (и
«слипшиеся» периоды). Обычные выходные прямоугольником **не** выделяются.

Каждый праздник / слитный период — один прямоугольник (текст `<p></p>`):
- `x` = начало периода;
- `width = 20 × n`, где `n` — число нерабочих дней подряд (`x + 20n` = конец);
- `y` = `y недель + height недель` (нижний край недельного ряда оси);
- `height` = высота RoadMap + запас;
- стиль: `fillColor "#FFD494"`, `fillStyle "h"`, `strokeColor "#FFDD2D"`, `strokeWidth 2`,
  `shape "1"`, **`alpha 30`**.

```json
{
  "type": "shape", "shape": "1",
  "size": { "width": 197, "height": 1336 },
  "position": { "x": 2002.5, "y": 186 },
  "text": "<p></p>",
  "style": {
    "fillColor": "#FFD494", "fillStyle": "h", "strokeColor": "#FFDD2D",
    "strokeStyle": "s", "strokeWidth": 2,
    "textAlign": "s", "textColor": "#3A3A3A",
    "textFontFamily": "Oswald, Segoe UI Emoji", "textFontSize": 10, "textVerticalAlign": "m"
  }
}
```

## Шрифт

Везде **Oswald**, размер по умолчанию **14** (подписи осей и текст в барах).

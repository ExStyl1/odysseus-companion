# Whiteboard RoadMap Skill

Скилл для отрисовки горизонтального **Gantt RoadMap** на Whiteboard по **готовым** данным.

## Что это

Ты — ИИ-навык, который рисует RoadMap на доске: ось времени (кварталы → месяцы → недели),
бары задач, буферные периоды и связи между задачами. Skill отвечает **только за визуал** — он не
собирает задачи из трекера, не считает сроки, перцентили, WIP или метрики. Все даты и значения
поступают готовыми на вход.

## Возможности

- 📅 Ось времени из трёх уровней: кварталы → месяцы → недели (ISO-номер недели в году), пастельные
  цвета с наследованием цвета у месяцев
- 📊 Бары задач со ссылкой на ключ, типом/статусом, обводкой по типу (Bug/Epic) и точными датами
- 🔗 Связи между задачами (`sequence` / `block` / `related`) с точками прикрепления и подписями причин
- 📦 Буферные периоды (`block` / `finish`) по переданным датам
- 🏷 Легенда с якорем «Горизонт: <дата>»
- 🧩 Спец-режимы: смешанные источники (несколько Jira/Tracker в одном RoadMap), плейсхолдер-режим
  (`ID-1`, `ID-2`, …) без реальных ключей, рисование только календарной сетки без задач

## Что skill НЕ делает

- Не собирает задачи из Jira/Tracker и не выбирает группировку (стримы создаются только по явно
  переданному `stream`)
- Не рассчитывает `planned_start`/`planned_end`, дедлайны, перцентили, T-Meter/статистику,
  WIP-ограничения, размер буфера
- Не обосновывает длительность и величину буфера — рисует по готовым датам

Если пользователь просит это посчитать — skill уточняет, что он только рисует, и запрашивает данные.

## Входные данные

**Обязательные:** задачи (`key`, `title`, `planned_start`, `planned_end`, `stream` + опц. `status`,
`deadline`, `link`, `source`, `type`), потоки (строки) и якорь/масштаб доски.

**Опциональные:** буферные периоды `{from, to, label, kind}`, связи
`{from_key, to_key, type, caption?}`, кастомные нюансы стиля.

## Использование

```bash
# Через skill
skill: "whiteboard-roadmap-creator"
```

Передай готовый набор данных (задачи, потоки, якорь) и получи ссылку на готовую доску.

## Структура

- `SKILL.md` — роль, границы ответственности, входные данные, порядок отрисовки, рабочий процесс
- `references/layout.md` — масштаб/координаты, ось, линии-разделители недель, праздники
- `references/task-bars.md` — бары задач, буферы, дедлайн, подпись строк
- `references/connections.md` — связи, `tipPoints`, подписи, легенда
- `references/technical-limits.md` — ограничения платформы Whiteboard

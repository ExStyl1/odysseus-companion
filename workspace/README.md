# Общая рабочая область

Откройте эту папку в Nessy Desktop и запускайте Nessy CLI из неё.
Она подключена к общему профилю Odysseus и содержит skill `odysseus-workspace`.
Перед использованием подтвердите доверие проекту в каждом приложении.

## Каталог навыков

- [Каталог навыков Nessy.md](Каталог%20навыков%20Nessy.md) — чтение в Nessy Desktop,
  подборки по ролям и ссылка «Применить в Nessy» у каждого навыка.
- [Каталог навыков Nessy.html](Каталог%20навыков%20Nessy.html) — автономная версия
  с поиском, фильтрами и карточками; открывается обычным браузером.

В карточке укажите свою задачу и нажмите «Применить в Nessy». Откроется новый
чат с запросом: выберите рабочий проект, проверьте текст и нажмите Enter.
Если запрос ещё не сформулирован, навык сначала поможет уточнить исходные данные.
Для перехода требуется установленный Nessy Desktop с обработчиком `nessy://`.
Если переход не сработал, скопируйте запрос кнопкой в карточке.
Файл сам не отправляет сообщения и не запускает корпоративные операции.

Обе версии обновляются командой `npm run catalog:build` из корня Odysseus.

Добавляйте MCP в `../shared/mcp.json`, skills в `../shared/skills`,
агентов в `../shared/agents`, инструкции и правила в `../shared/rules`.
Из корня Odysseus выполните `node tools/odysseus.mjs sync` или запустите `watch`.

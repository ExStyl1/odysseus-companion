# Технические ограничения Whiteboard

Обязательно прочитай перед планированием вызовов. Live-схема `create_board_elements` — единственный
источник правды по типам элементов, полям и лимитам; при противоречии с этим файлом доверяй схеме.

## Правила

- `text` любого элемента (shape, text, sticker и др.) обязан **начинаться с `<p>` и заканчиваться
  `</p>`**.
- Максимум **100 элементов** на один вызов `create_board_elements` / `update_board_elements`.
  Большая доска → разбивай на последовательные вызовы, сохраняя общий план координат и используя
  `id` из ответов при необходимости.
- `update_board_elements` при изменении `size` **обязательно** требует `size.height`.
- `textFontSize` у shape **только для чтения** (подбирается автоматически) — не пытайся задавать.
- Недели/скругления — `shape: "RectangleRounded"` (значение `"1"` при создании **невалидно**).
- Нет delete-инструмента — скрывай ненужное через `alpha: 0`.
- Координаты баров кратны 20px и прилегают — проверяй границы.
- Элементы, к которым крепятся линии/связи (недели, бары), создаются раньше; их `id` из ответа
  создания нужно **сохранять** и использовать при создании линий/связей.
- Если целевая доска или данные, требуемые схемой, недоступны — запроси только недостающее.
- Не создавай промежуточные файлы-доски, сериализованные диаграммы или локальные артефакты рендера.

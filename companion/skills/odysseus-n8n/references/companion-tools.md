# Контракт корпоративного n8n

- `corporate_n8n_sync({})` — обновить локальный снимок. Нужны корпоративная сеть и ключ Public API.
- `corporate_n8n_workflow_list({query, offset, limit})` — получить метаданные процессов из снимка.
- `corporate_n8n_workflow_get({id})` — прочитать сохранённую схему по ID.
- `corporate_n8n_executions({})` — получить метаданные истории без содержимого запусков.

Для создания или изменения процесса подготовь JSON с полями name, nodes, connections и settings. Используй подтверждённые типы узлов корпоративного экземпляра. Проверь обе стороны каждой связи, не включай секреты и сохрани реальные имена полей. Привязки credentials и пробный запуск выполняются в корпоративном редакторе.

При недоступности API сообщи дату снимка, если он имеется. Отсутствие результата при незагруженном снимке не означает, что на сервере нет процессов.

подключённых проектов для Nessy CLI и Nessy Desktop. Раздельные механизмы
обновления приложений сохранены.

## Разрешённые сценарии

- Текущий агент Nessy и его уже настроенная модель.
- Локальные файлы, Git, тесты, анализ данных, Python/Node.js и библиотеки.
- Браузер: чтение страниц, взаимодействие, скриншоты и локальное тестирование.
- Obsidian и его локальный CLI/API, Markdown, Bases и JSON Canvas.
- Graphify без Gemini и внешних БД: локальный AST, существующие графы и
  семантический анализ средствами текущего агента.
- HyperFrames/Remotion, FFmpeg, Manim и локальная обработка медиа.
- Локальные LSP/MCP-адаптеры языковых серверов.
- Планирование, TDD, ревью, редактура, дизайн и маркетинговые материалы
  на основе предоставленных данных; локальное создание изображений через
  SVG/HTML/canvas/Pillow и имеющиеся ассеты.

Локальные инструменты нужно установить отдельно, если их нет. Навык не
устанавливает FFmpeg, браузер, Obsidian, Graphify или движок рендера.

- Figma API, `last30days`, Caveman Cloud, отправка файлов на внешнюю модель
  через `caveman-compress` и отдельный загрузчик `video-download`.
- tldraw, ComfyUI, After Effects/Bodymovin и отдельный Blender-пайплайн.

Точный перечень удалённых имён с причинами хранится в
`shared/skills-policy.json`. Исходные удалённые каталоги и прежние entrypoints
сохранены для восстановления в `.odysseus/removed-skills-*` и не обнаруживаются
как активные навыки.

## Смешанные наборы

Руководства всех оставленных навыков первоначального набора содержат явный локальный
профиля. Он сужает
upstream-сценарии: облачные ветки, настройка ключей, вход в дополнительных
провайдеров, облачный рендер и автоматические удалённые обновления skills
не используются. Это инструкции для агента, а не сетевой sandbox процессов.

HyperFrames/OpenMontage используют готовые локальные ассеты, локальный рендер,
смонтированные файлы и установленные офлайн-движки озвучки/транскрибации.
Если локального входного файла или движка нет, агент сообщает об этом вместо
переключения на облако. `pr-to-video` работает с локальным diff/экспортом PR
или данными, полученными через разрешённый браузер; без GitHub API.

Маркетинговые навыки создают планы, тексты, макеты и отчёты по локальным данным.
Они не подключают рекламные кабинеты, CRM, рассылки или аналитику через API.
Браузерные действия остаются в рамках отдельной задачи пользователя.

Браузер, субагенты и LSP используют доступные средства текущего хоста.
Импортированный OmO-текст не является основанием устанавливать другой агентный
runtime. При отсутствии совместимого локального адаптера агент сообщает,
какая возможность недоступна.

## Происхождение и проверка

`UPSTREAM.json` внутри каждого навыка сохраняет исходный URL, Git SHA,
frontmatter и список адаптаций. `shared/skills.lock.json` содержит текущий
состав и SHA-256 каждого файла. Лицензии и сопутствующие ресурсы сохранены.
`shared/skills-policy.json` фиксирует базовый профиль, удалённые навыки и явно
разрешённые исключения нового набора. У них `executionProfile` равен
`user-approved-exception`, у первоначального набора — `local-browser-obsidian`.

```bash
node tools/odysseus.mjs sync
node tools/odysseus.mjs sync --check
npm test
```

После синхронизации обновите список навыков или начните новую сессию в
приложении. Проверки каталога не заменяют запуск конкретного локального
инструмента; облачные сервисы при отборе не подключались.

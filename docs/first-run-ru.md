# Первый запуск: перенос из Nessy

При запуске через команды Odysseus программа автоматически создаёт собственные профили и копирует найденные данные. Старые профили не изменяются. Повторный запуск не выполняет импорт заново и сохраняет ваши новые правки.

Поиск проверяет `.nessy`, `.nessy-cli`, `.nessy-agent`, `.nessy-desktop`, `.nestor`, стандартные каталоги конфигурации ОС и пути `NESSY_HOME`, `NESSY_CONFIG_DIR`, `NESSY_RUNTIME_DIR`, `NESTOR_HOME`. Установленный CLI ищется в PATH без запуска. `Nessy Desktop.app` ищется в Applications, Downloads, Desktop и папке проекта. Из приложения читаются выбранные ресурсы, включая `app.asar`; код приложения не запускается.

Основные профили сохраняются в `~/.odysseus/profiles/cli` и `~/.odysseus/profiles/desktop`. Дополнительные найденные профили, данные Nestor и ресурсы приложения сохраняются в `profiles/imported`. Можно изменить корневую папку переменной `ODYSSEUS_DATA_DIR`.

Переносятся чаты, настройки, модели, MCP, расширения, навыки и файлы учётных данных в исходном формате. Абсолютные пути в JSON-конфигурации перенаправляются на копии. Неизвестные форматы сохраняются без преобразования; доступность внешних сервисов и совместимость старых расширений зависят от их окружения. Перенос зашифрованного файла сам по себе не гарантирует авторизацию на другом компьютере.

Глобальные и встроенные навыки добавляются в профили CLI и существующих рабочих пространств Desktop. При совпадении сохраняется уже имеющийся навык рабочего пространства. Кеши, временные блокировки, ссылки и файлы процессов пропускаются. Отчёт о переносе и предупреждения находятся в `profiles/installation.json`; в консоль секреты не выводятся.

Проверить поиск без записи: `npm run setup -- --check`. Выполнить перенос отдельно от запуска: `npm run setup`. Если остался незавершённый журнал прежней синхронизации, сначала выполните `npm run sync:personal`, затем повторите установку. Исходные данные нельзя удалять вручную для обхода этой проверки.

Это однократный перенос. Последующая общая синхронизация CLI/Desktop использует профили Odysseus. Данные исходных Nessy не отслеживаются постоянно. Если ничего не найдено, создаются пустые профили.

# Оформление Odysseus CLI

CLI использует штатные настройки `ui.customBannerTitle`, `ui.customAsciiArt` и `ui.customThemes`, которые поддерживает установленная версия CLI. Название **ODYSSEUS CLI**, блочная надпись ODYSSEUS и бронзовые палитры Odysseus Dark/Light хранятся в `integrations/cli/settings.json`. Для изменения оформления не требуется менять исходники или пересобирать CLI.

Запуск через `tools/run-component.mjs cli`, включая кнопку Desktop, подключает этот файл как системные настройки по умолчанию через `NESSY_CLI_SYSTEM_DEFAULTS_PATH`. Поэтому оформление работает при первом запуске с новым профилем. Уже заданный пользователем путь системных настроек по умолчанию сохраняется.

Общий профиль устанавливает те же настройки в пользовательский профиль CLI транзакцией с резервной копией. При первом применении выбирается палитра Odysseus; последующие переключения светлой/тёмной темы синхронизируются с Desktop. Старые имена Nessy Dark/Light принимаются при миграции, новые записи используют Odysseus Dark/Light. Явно выбранные пользователем другие темы сохраняются. Системный режим Desktop сохраняется; для него CLI использует свою выбранную палитру, поскольку штатный автоматический режим CLI не выбирает пользовательские темы.

Для повторного применения: `npm run sync:personal`. Новое оформление видно при следующем запуске CLI через кнопку **«Открыть в CLI»**. Цвет фона окна задаёт системный терминал; тема Odysseus задаёт текст, акценты, рамки, подсветку и семантические цвета CLI. Имена моделей, учётные данные и команды поставщика не переименовываются.

Проверено 2026-10-21: 76 корневых тестов и 82 целевых нативных теста CLI. Отдельная проверка неизменённого установленного `dist` подтвердила чтение баннера и обеих палитр штатными функциями CLI. Запуск из Desktop подтверждается квитанцией реально запущенного процесса. Доступ автоматизации к интерфейсу Terminal ограничен; визуальная проверка его окна не заявляется.

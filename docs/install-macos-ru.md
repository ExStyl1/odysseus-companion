# Установка и сборка Odysseus для macOS

## Для пользователя

1. Откройте DMG и перетащите **Odysseus.app** в **Applications**.
2. Запустите Odysseus из Applications, Spotlight или Launchpad.
3. После первого открытия запустите новое окно Терминала и введите `od`.

CLI запускается в том терминале, где введена команда. Кнопка «Открыть в CLI» в Desktop открывает системный Terminal. Аргументы передаются как обычно: `od --help`, `od --resume`. Текущая папка терминала становится папкой проекта.

Node.js, Bun, CLI, Desktop, SDK и общие навыки входят в приложение. Пользователю не нужны исходники, npm install или компиляция. Первый запуск копирует рабочие файлы в `~/Library/Application Support/Odysseus/runtime` и переносит найденные профили Nessy в `~/.odysseus/profiles`. Крупные наборы навыков и данных увеличивают время первого запуска; универсальное обещание установки за фиксированное число секунд невозможно.

Команда устанавливается в `~/.local/bin/od`; этот каталог добавляется в начало PATH для новых окон zsh/bash. Исходные профили Nessy сохраняются. При замене приложения новой версией чаты, рабочая папка и состояние базы знаний сохраняются. Пользовательские изменения общих навыков не заменяются шаблонами сборки. Приложение следует открыть после перемещения: это обновляет путь команды `od`.

Интернет и авторизация нужны самим внешним провайдерам. Graphify и его Python-окружение на новом компьютере устанавливаются отдельно при включении базы знаний; этот дополнительный движок не входит в DMG.

## Для разработчика

Нужны macOS, Node.js 22+, Bun и установленные зависимости обоих проектов. Выполните `npm run build:mac`. Сборщик создаёт готовый `.app`, DMG и SHA-256 в `dist/`. Архитектура совпадает с компьютером сборки: arm64 для Apple Silicon, x64 для Intel. Для обеих архитектур запускайте сборку на соответствующих Mac.

`ODYSSEUS_BUN=/путь/к/bun` задаёт Bun; по умолчанию используется `.odysseus/runtime/bun`. Команда `npm run build:mac -- --skip-build` повторно упаковывает уже собранные компоненты и предназначена для разработки упаковки.

GitHub Actions workflow `Build Odysseus for macOS` собирает DMG вручную или при отправке тега `odysseus-v*`. Результат доступен как артефакт запуска; автоматической публикации или загрузки секретов нет.

## Подпись для распространения

Обычная локальная сборка не подписана Developer ID и не notarized. На чужом Mac Gatekeeper может блокировать её. Для публичного релиза нужен Apple Developer ID; сертификат должен быть доступен сборщику.

Задайте `CSC_NAME` и поддерживаемые electron-builder реквизиты notarization Apple (`APPLE_ID`, `APPLE_APP_SPECIFIC_PASSWORD`, `APPLE_TEAM_ID` либо параметры App Store Connect API), затем выполните `npm run build:mac -- --signed`. Сборщик подписывает и notarizes приложение; DMG подписывается отдельно. Локальные проверки без сертификата не подтверждают notarization.

Обновление компонентов из исходников остаётся независимым: сборка использует текущие версии двух проектов. Установленный комплект обновляется заменой приложения; автоматический сетевой updater и сервер релизов здесь не настраиваются.

Интерактивный CLI включает палитру Odysseus даже при унаследованном `NO_COLOR` от среды запуска. Для явного отключения используйте `ODYSSEUS_NO_COLOR=1 od`. Перенаправленный вывод не получает принудительные цвета.

Кнопка «Открыть в CLI» запускает новый `od` в системном Terminal. Кнопка «Продолжить в CLI» в заголовке чата сохраняет историю и запускает `od --resume` в папке проекта; пустой чат открывает новый CLI. При первом использовании macOS может попросить разрешить Odysseus управлять Terminal. Это штатный запрос Automation.
